## Notes for Technical Content Writer

**Style Guide**:
- Use beginner-friendly language (assume no prior robotics knowledge, but basic programming literacy)
- Avoid jargon without definition
- Analogies should be universally relatable (not domain-specific)
- Code examples should be self-contained and executable

**Skills to Use**:
- `analogy-concept-explainer`: For Analogy section
- `mermaid-diagram-generator`: For Diagram section
- `ros2-code-example-writer`: For Example and Exercise sections (Tier A, B, C variants)

**Constitution Compliance**:
- Three-Tier Imperative: Ensure Tier A is complete and CPU-only
- Content Accuracy: Cite references for all technical claims
- Educational Clarity: Follow Analogy → Concept → Diagram → Example → Exercise → Summary → Quiz structure
- Safety First: Add :::danger blocks before any hardware instructions
