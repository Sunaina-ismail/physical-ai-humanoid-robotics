# Chapter 15: Domain Randomization

## Introduction

Domain randomization is a powerful technique in robotics and AI that addresses the "reality gap" - the challenge of transferring models trained in simulation to real-world applications. By systematically varying environmental conditions, physics parameters, and sensor characteristics during training, domain randomization creates AI models that are robust to the differences between simulation and reality. This chapter explores how to implement domain randomization in robotics simulation environments.

## Learning Objectives

By the end of this chapter, you will be able to:
- Understand the principles of domain randomization
- Implement randomization techniques for physics parameters
- Apply rendering domain randomization
- Create sensor domain randomization for robust perception
- Evaluate sim-to-real transfer performance

## Real-World Analogy: Teaching a Child in Multiple Environments

Domain randomization is like teaching a child to recognize a cat not just in your living room, but in different lighting conditions, from different angles, in various environments (park, car, friend's house), with different cat breeds, and in different poses. If you only show the child cats in your living room, they might not recognize a cat outside. Similarly, training robots in a single simulation environment creates models that fail when transferred to the real world. Domain randomization shows the AI multiple "versions" of reality to build robust understanding.

## Core Concepts

### 1. The Reality Gap Problem

The reality gap refers to differences between simulation and reality that cause models trained in simulation to fail in real-world deployment:
- Visual differences: lighting, textures, colors
- Physics differences: friction, dynamics, contact models
- Sensor differences: noise, resolution, calibration
- Environmental differences: layouts, objects, conditions

### 2. Domain Randomization Strategy

Domain randomization addresses the reality gap by:
- Randomizing simulation parameters during training
- Creating diverse training environments
- Building robust models insensitive to domain differences
- Improving sim-to-real transfer capabilities

### 3. Types of Randomization

- **Visual Randomization**: Lighting, textures, colors, camera parameters
- **Physics Randomization**: Friction, mass, damping, restitution
- **Sensor Randomization**: Noise, resolution, calibration parameters
- **Environmental Randomization**: Object placement, layouts, dynamics

# Physics domain randomization implementation
import numpy as np
import random
from omni.isaac.core.utils.prims import get_prim_at_path
from pxr import UsdPhysics

class PhysicsDomainRandomizer:
    def __init__(self, world):
        self.world = world
        self.randomization_ranges = {
            'friction': (0.1, 1.0),           # Static and dynamic friction
            'restitution': (0.0, 0.8),        # Bounciness (0 = no bounce, 1 = fully bouncy)
            'mass_multiplier': (0.5, 2.0),    # Mass variation
            'damping': (0.0, 10.0),           # Joint damping
            'stiffness': (100, 10000)         # Joint stiffness
        }

    def randomize_physics_properties(self, prim_path):
        """Randomize physics properties for a given prim"""
        prim = get_prim_at_path(prim_path)

        # Randomize friction
        static_friction = np.random.uniform(
            self.randomization_ranges['friction'][0],
            self.randomization_ranges['friction'][1]
        )
        dynamic_friction = np.random.uniform(
            self.randomization_ranges['friction'][0],
            self.randomization_ranges['friction'][1]
        )

        # Randomize restitution (bounciness)
        restitution = np.random.uniform(
            self.randomization_ranges['restitution'][0],
            self.randomization_ranges['restitution'][1]
        )

        # Apply physics properties
        physics_api = UsdPhysics.RigidBodyAPI(prim)
        if physics_api:
            physics_api.CreateFrictionAttr().Set((static_friction + dynamic_friction) / 2)
            physics_api.CreateRestitutionAttr().Set(restitution)

    def randomize_robot_dynamics(self, robot_prim_path):
        """Randomize robot joint dynamics"""
        # Get robot joints and randomize their properties
        joint_names = self._get_robot_joints(robot_prim_path)

        for joint_name in joint_names:
            joint_prim = get_prim_at_path(f"{robot_prim_path}/{joint_name}")

            # Randomize joint properties
            damping = np.random.uniform(
                self.randomization_ranges['damping'][0],
                self.randomization_ranges['damping'][1]
            )
            stiffness = np.random.uniform(
                self.randomization_ranges['stiffness'][0],
                self.randomization_ranges['stiffness'][1]
            )

            joint_api = UsdPhysics.JointAPI(joint_prim)
            if joint_api:
                joint_api.CreatePhysicsDampingAttr(damping)
                joint_api.CreatePhysicsStiffnessAttr(stiffness)

    def _get_robot_joints(self, robot_prim_path):
        """Get list of robot joint names"""
        # This would typically parse the robot's URDF/USD to find joints
        # For this example, we'll return a mock list
        return ["joint1", "joint2", "joint3", "joint4", "joint5", "joint6"]

    def apply_randomization_cycle(self):
        """Apply randomization at regular intervals during training"""
        # Get all physics-enabled objects in the scene
        physics_objects = self._get_physics_objects()

        for obj_path in physics_objects:
            self.randomize_physics_properties(obj_path)

        # Randomize robot dynamics
        robot = self.world.scene.get_object("sim_robot")
        if robot:
            self.randomize_robot_dynamics(robot.prim_path)

    def _get_physics_objects(self):
        """Get list of all physics-enabled objects in the scene"""
        # In practice, this would query the USD stage for physics-enabled prims
        # For this example, return a mock list
        return [
            "/World/Object_0",
            "/World/Object_1",
            "/World/Object_2",
            "/World/Floor"
        ]

class VisualDomainRandomizer:
    def __init__(self):

            specular_color=np.array([0.5, 0.5, 0.5]),
            metallic_factor=np.random.uniform(self.material_properties['metallic'][0],

        """Apply visual randomization to an object"""
        # Create unique material path for this randomization
        material_path = f"{object_prim_path}_material_{np.random.randint(1000, 9999)}"

        # Randomize material
        material = self.randomize_material_color(material_path)

        # Apply material to object

        return material

            self.camera_params['focal_length'][1]

        focus_distance = np.random.uniform(
            self.camera_params['focus_distance'][0],
            self.camera_params['focus_distance'][1]
        )

        # Apply parameters to camera
        camera.focal_length = focal_length
        camera.focus_distance = focus_distance

        # Randomize distortion parameters
        distortion_params = {
            'k1': np.random.uniform(self.camera_params['distortion_k1'][0],
                                  self.camera_params['distortion_k1'][1]),
            'k2': np.random.uniform(self.camera_params['distortion_k2'][0],
                                  self.camera_params['distortion_k2'][1]),
            'p1': np.random.uniform(self.camera_params['distortion_p1'][0],
                                  self.camera_params['distortion_p1'][1]),
            'p2': np.random.uniform(self.camera_params['distortion_p2'][0],
                                  self.camera_params['distortion_p2'][1])
        }

        return distortion_params

    def add_realistic_camera_noise(self, image):
        """Add realistic camera noise to simulate real sensor characteristics"""
        # Add different types of noise
        height, width, channels = image.shape

        # Photon shot noise (signal-dependent)
        signal_noise = np.random.poisson(image * 255) / 255.0

        # Read noise (signal-independent)
        read_noise = np.random.normal(0, 0.01, image.shape)

        # Pattern noise (fixed pattern)
        pattern_noise = np.random.uniform(-0.005, 0.005, (height, 1, channels))
        pattern_noise = np.tile(pattern_noise, (1, width, 1))

        # Combine noises
        noisy_image = image + signal_noise + read_noise + pattern_noise

        return np.clip(noisy_image, 0, 1)

class LidarDomainRandomizer:
    def __init__(self):
        self.lidar_params = {
            'range_accuracy': (0.01, 0.1),         # meters
            'angular_resolution': (0.1, 2.0),      # degrees
            'intensity_accuracy': (0.05, 0.2),     # intensity units
            'dropout_rate': (0.001, 0.05),         # probability of missed detection
            'motion_blur_factor': (0.0, 0.1),      # motion-induced errors
            'multi_path_interference': (0.0, 0.05) # multi-path effects
        }

    def randomize_lidar_characteristics(self, lidar_sensor):
        """Randomize LIDAR sensor characteristics"""
        # Randomize accuracy parameters
        range_noise_std = np.random.uniform(
            self.lidar_params['range_accuracy'][0],
            self.lidar_params['range_accuracy'][1]
        )

        dropout_rate = np.random.uniform(
            self.lidar_params['dropout_rate'][0],
            self.lidar_params['dropout_rate'][1]
        )

        return {
            'range_noise_std': range_noise_std,
            'dropout_rate': dropout_rate,
            'angular_resolution': np.random.uniform(
                self.lidar_params['angular_resolution'][0],
                self.lidar_params['angular_resolution'][1]
            ),
            'motion_blur_factor': np.random.uniform(
                self.lidar_params['motion_blur_factor'][0],
                self.lidar_params['motion_blur_factor'][1]
            )
        }

    def apply_lidar_noise(self, scan_data, params):
        """Apply realistic LIDAR noise and artifacts"""
        # Add range-dependent noise
        distances = scan_data.copy()
        noise_std = params['range_noise_std'] * (1 + 0.1 * distances)  # Noise increases with distance
        range_noise = np.random.normal(0, noise_std, distances.shape)
        noisy_distances = distances + range_noise

        # Apply dropout (missed detections)
        dropout_mask = np.random.random(distances.shape) < params['dropout_rate']
        noisy_distances[dropout_mask] = float('inf')  # Set to max range for missed detections

        # Apply angular resolution effects (simplified)
        # In reality, this would affect the discretization of the scan

        return np.maximum(noisy_distances, 0.05)  # Ensure minimum distance

# Complete domain randomization system
import time
from omni.isaac.core.utils.stage import get_current_stage

class DomainRandomizationManager:
    def __init__(self, world):
        self.world = world
        self.physics_randomizer = PhysicsDomainRandomizer(world)
        self.visual_randomizer = VisualDomainRandomizer()
        self.camera_randomizer = CameraDomainRandomizer()
        self.lidar_randomizer = LidarDomainRandomizer()
        self.env_randomizer = EnvironmentDomainRandomizer(world)

        # Randomization schedule
        self.randomization_schedule = {
            'physics': {'interval': 50, 'enabled': True},      # Every 50 steps
            'visual': {'interval': 100, 'enabled': True},      # Every 100 steps
            'environment': {'interval': 200, 'enabled': True}  # Every 200 steps
        }

        self.step_count = 0

    def apply_domain_randomization(self):
        """Apply domain randomization based on schedule"""
        self.step_count += 1

        # Apply physics randomization
        if (self.randomization_schedule['physics']['enabled'] and
            self.step_count % self.randomization_schedule['physics']['interval'] == 0):
            self.physics_randomizer.apply_randomization_cycle()
            print(f"Applied physics randomization at step {self.step_count}")

        # Apply visual randomization
        if (self.randomization_schedule['visual']['enabled'] and
            self.step_count % self.randomization_schedule['visual']['interval'] == 0):
            self._apply_visual_randomization()
            print(f"Applied visual randomization at step {self.step_count}")

        # Apply environment randomization
        if (self.randomization_schedule['environment']['enabled'] and
            self.step_count % self.randomization_schedule['environment']['interval'] == 0):
            self.env_randomizer.randomize_scene_layout()
            print(f"Applied environment randomization at step {self.step_count}")

    def _apply_visual_randomization(self):
        """Apply visual randomization to scene objects"""
        # Randomize lighting
        lighting_params = self.visual_randomizer.randomize_environment_lighting()

        # In practice, apply these parameters to the scene lighting

        # Randomize materials for some objects
        scene_objects = self._get_scene_objects()

## Best Practices

### 1. Graduated Randomization
- Start with narrow ranges and gradually expand
- Monitor performance to ensure learning still occurs
- Balance diversity with task feasibility

### 2. Correlated Randomization
- Randomize related parameters together (e.g., lighting and colors)
- Maintain physical plausibility across randomizations
- Consider real-world correlations in parameter selection

### 3. Validation Strategy
- Test on a held-out set of real conditions
- Monitor both simulation and real-world performance
- Use ablation studies to identify effective randomizations
