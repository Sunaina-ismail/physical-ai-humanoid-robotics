# Chapter 23: Voice to Navigation

## Introduction

Voice to Navigation represents the convergence of speech recognition, natural language processing, and autonomous navigation systems, creating intuitive interfaces that allow humans to communicate with robots using natural language. This technology enables users to command robots with simple voice instructions like "Go to the kitchen" or "Bring me the red cup," bridging the gap between human communication and robotic action. This chapter explores the integration of speech recognition, NLP, and navigation systems to create seamless voice-controlled navigation capabilities.

- Implement speech recognition systems for navigation commands

- Evaluate voice navigation system performance and accuracy

## Real-World Analogy: The Conversational Assistant

Think of voice navigation like giving directions to a friend who is new to your city. Instead of using complex coordinates or technical navigation terms, you use natural language like "Go straight for two blocks, then turn right at the coffee shop, and it's the third building on your left." Voice navigation systems interpret these natural language instructions and translate them into precise navigation commands that robots can execute, making human-robot interaction more intuitive and accessible.

## Core Concepts

### 1. Speech Recognition Pipeline

Voice to Navigation systems follow a multi-stage pipeline:

- **Audio Capture**: Recording speech from microphones
- **Preprocessing**: Noise reduction and audio enhancement
- **Feature Extraction**: Converting audio to speech features
- **Recognition**: Converting speech to text
- **NLP Processing**: Understanding the meaning of text commands
- **Navigation Planning**: Converting commands to navigation goals

### 2. Natural Language Understanding

NLP for navigation involves understanding spatial and directional concepts:

- **Entity Recognition**: Identifying locations, objects, and landmarks
- **Intent Classification**: Determining navigation actions (go to, find, follow)
- **Spatial Reasoning**: Understanding spatial relationships and directions
- **Context Awareness**: Using environmental and situational context

### 3. Voice Navigation Challenges

- **Ambiguous Commands**: "Go to the table" when multiple tables exist
- **Environmental Noise**: Background noise affecting recognition accuracy
- **Multi-step Instructions**: Complex commands requiring sequence execution
- **Real-time Processing**: Handling speech in real-time for responsive navigation

```python
#!/usr/bin/env python3

"""
Voice Navigation System
Integrates speech recognition with navigation commands
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import PoseStamped
from nav2_msgs.action import NavigateToPose
from rclpy.action import ActionClient
from rclpy.qos import QoSProfile
import speech_recognition as sr
import threading
import queue
import re
from typing import Dict, List, Optional


class VoiceNavigation(Node):
    def __init__(self):
        super().__init__('voice_navigation')

        # Initialize speech recognizer
        self.recognizer = sr.Recognizer()
        self.microphone = sr.Microphone()

        # Set energy threshold for silence detection
        self.recognizer.energy_threshold = 4000
        self.recognizer.dynamic_energy_threshold = True

        # Publishers and subscribers
        self.command_pub = self.create_publisher(String, 'voice_commands', 10)
        self.status_pub = self.create_publisher(String, 'voice_status', 10)

        # Navigation action client
        self.nav_client = ActionClient(self, NavigateToPose, 'navigate_to_pose')

        # Command queue for processing
        self.command_queue = queue.Queue()
        self.command_thread = threading.Thread(target=self.process_commands, daemon=True)
        self.command_thread.start()

        # Location mappings (in a real system, these would come from semantic mapping)
        self.location_map = {
            'kitchen': [2.0, 2.0, 0.0],
            'living room': [0.0, 0.0, 0.0],
            'bedroom': [3.0, -1.0, 0.0],
            'office': [-2.0, 1.0, 0.0],
            'bathroom': [1.0, -2.0, 0.0],
            'dining room': [-1.0, -1.0, 0.0]
        }

        # Start voice recognition in separate thread
        self.voice_thread = threading.Thread(target=self.listen_for_voice, daemon=True)
        self.voice_thread.start()

        self.get_logger().info('Voice Navigation system initialized')

    def listen_for_voice(self):
        """Listen for voice commands in a separate thread"""
        self.get_logger().info('Starting voice recognition...')

        with self.microphone as source:
            self.recognizer.adjust_for_ambient_noise(source)

        while rclpy.ok():
            try:
                with self.microphone as source:
                    self.get_logger().debug('Listening for voice command...')
                    audio = self.recognizer.listen(source, timeout=5.0, phrase_time_limit=10.0)

                # Recognize speech
                text = self.recognizer.recognize_google(audio)
                self.get_logger().info(f'Recognized: {text}')

                # Publish recognized command
                cmd_msg = String()
                cmd_msg.data = text.lower()
                self.command_pub.publish(cmd_msg)

                # Add to processing queue
                self.command_queue.put(text.lower())

            except sr.WaitTimeoutError:
                continue  # No speech detected, continue listening
            except sr.UnknownValueError:
                self.get_logger().warn('Could not understand audio')
            except sr.RequestError as e:
                self.get_logger().error(f'Speech recognition error: {e}')
            except Exception as e:
                self.get_logger().error(f'Voice recognition error: {e}')

    def process_commands(self):
        """Process voice commands in separate thread"""
        while rclpy.ok():
            try:
                command = self.command_queue.get(timeout=1.0)
                self.process_voice_command(command)
            except queue.Empty:
                continue
            except Exception as e:
                self.get_logger().error(f'Command processing error: {e}')

    def process_voice_command(self, command: str):
        """Process a voice command and execute navigation"""
        self.get_logger().info(f'Processing command: {command}')

        # Update status
        status_msg = String()
        status_msg.data = f'Processing: {command}'
        self.status_pub.publish(status_msg)

        # Parse command using regular expressions
        if 'go to' in command or 'navigate to' in command or 'move to' in command:
            self.handle_navigation_command(command)
        elif 'stop' in command or 'halt' in command:
            self.handle_stop_command()
        elif 'come here' in command or 'come to me' in command:
            self.handle_come_here_command()
        else:
            self.get_logger().warn(f'Unknown command: {command}')
            self.handle_unknown_command(command)

    def handle_navigation_command(self, command: str):
        """Handle navigation commands like 'go to kitchen'"""
        # Extract destination from command
        destination = self.extract_destination(command)

        if destination:
            # Check if destination exists in location map
            if destination in self.location_map:
                target_pose = self.location_map[destination]
                self.send_navigation_goal(target_pose[0], target_pose[1], target_pose[2])
            else:
                self.get_logger().warn(f'Unknown destination: {destination}')
                self.ask_for_clarification(f"Unknown location '{destination}'. Please specify a known location.")
        else:
            self.ask_for_clarification("Please specify a destination. For example: 'Go to kitchen'")

    def extract_destination(self, command: str) -> Optional[str]:
        """Extract destination from navigation command"""
        # Look for location names in the command
        for location in self.location_map.keys():
            if location in command:
                return location

        # If no known location found, return None
        return None

    def handle_stop_command(self):
        """Handle stop navigation command"""
        self.get_logger().info('Stop command received')
        # In a real system, you would cancel the current navigation goal
        # For this example, we'll just log the command

    def handle_come_here_command(self):
        """Handle 'come here' command - requires localization to user position"""
        self.get_logger().info('Come here command received')
        # This would require additional sensors to locate the user
        # For this example, we'll navigate to a default location
        self.send_navigation_goal(0.0, 0.0, 0.0)

    def handle_unknown_command(self, command: str):
        """Handle unknown commands"""
        self.get_logger().warn(f'Unknown command: {command}')
        self.ask_for_clarification(f"Sorry, I didn't understand '{command}'. Try commands like 'Go to kitchen' or 'Stop'.")

    def ask_for_clarification(self, message: str):
        """Request clarification from user (in a real system, this would use text-to-speech)"""
        self.get_logger().info(f'Clarification needed: {message}')
        # In a real system, this would use text-to-speech to ask for clarification

    def send_navigation_goal(self, x: float, y: float, theta: float = 0.0):
        """Send navigation goal to Nav2"""
        # Wait for action server
        if not self.nav_client.wait_for_server(timeout_sec=5.0):
            self.get_logger().error('Navigation server not available')
            return

        # Create navigation goal
        goal_msg = NavigateToPose.Goal()
        goal_msg.pose.header.frame_id = 'map'
        goal_msg.pose.header.stamp = self.get_clock().now().to_msg()
        goal_msg.pose.pose.position.x = x
        goal_msg.pose.pose.position.y = y
        goal_msg.pose.pose.position.z = 0.0

        # Convert angle to quaternion
        import math
        goal_msg.pose.pose.orientation.z = math.sin(theta / 2.0)
        goal_msg.pose.pose.orientation.w = math.cos(theta / 2.0)

        # Send goal
        self.get_logger().info(f'Sending navigation goal to ({x}, {y})')
        future = self.nav_client.send_goal_async(goal_msg)
        future.add_done_callback(self.goal_response_callback)

    def goal_response_callback(self, future):
        """Handle navigation goal response"""
        goal_handle = future.result()
        if not goal_handle.accepted:
            self.get_logger().info('Goal rejected')
            return

        self.get_logger().info('Goal accepted')
        result_future = goal_handle.get_result_async()
        result_future.add_done_callback(self.get_result_callback)

    def get_result_callback(self, future):
        """Handle navigation result"""
        result = future.result().result
        self.get_logger().info(f'Navigation completed with result: {result}')

    def get_supported_commands(self) -> List[str]:
        """Get list of supported voice commands"""
        return [
            'Go to [location]',
            'Navigate to [location]',
            'Move to [location]',
            'Stop',
            'Halt',
            'Come here',
            'Come to me'
        ]


def main(args=None):
    rclpy.init(args=args)

    voice_nav = VoiceNavigation()

    try:
        rclpy.spin(voice_nav)
    except KeyboardInterrupt:
        voice_nav.get_logger().info('Shutting down voice navigation system')
    finally:
        voice_nav.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

#!/usr/bin/env python3

"""
Context-Aware Voice Navigation
Integrates environmental context with voice navigation commands
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool
from geometry_msgs.msg import PoseStamped, Point

import math
from typing import Dict, List, Tuple, Optional
from dataclasses import dataclass


@dataclass
class NavigationContext:
    """Data class for navigation context"""
    current_location: Tuple[float, float, float]
    nearby_objects: List[str]
    room_type: str
    time_of_day: str
    user_proximity: float
    obstacles: List[Tuple[float, float]]


class ContextAwareVoiceNavigation(Node):
    def __init__(self):
        super().__init__('context_aware_voice_nav')

        # CV Bridge for image processing
        self.bridge = CvBridge()

        # Subscribers
        self.voice_command_sub = self.create_subscription(
            String, 'voice_commands', self.voice_command_callback, 10

        )

        # Publishers
        self.context_pub = self.create_publisher(String, 'navigation_context', 10)
        self.resolved_command_pub = self.create_publisher(String, 'resolved_commands', 10)
        self.navigation_goal_pub = self.create_publisher(PoseStamped, 'navigation_goal', 10)

        # Navigation context
        self.current_context = NavigationContext(
            current_location=(0.0, 0.0, 0.0),
            nearby_objects=[],
            room_type='unknown',
            time_of_day='unknown',
            user_proximity=0.0,
            obstacles=[]
        )

        # Object detection results
        self.detected_objects = []
        self.user_detected = False
        self.user_distance = 0.0

        # Ambiguous command resolution
        self.location_ambiguity_resolver = {
            'table': ['kitchen table', 'dining table', 'office desk'],
            'chair': ['kitchen chair', 'office chair', 'living room chair'],
            'couch': ['living room couch', 'family room couch']
        }

        self.get_logger().info('Context-Aware Voice Navigation initialized')

    def current_pose_callback(self, msg):
        """Update current location in context"""
        self.current_context.current_location = (
            msg.pose.position.x,
            msg.pose.position.y,
            self.quaternion_to_yaw(msg.pose.orientation)
        )

    def laser_scan_callback(self, msg):
        """Update obstacles in context"""
        obstacles = []
        angle = msg.angle_min

        for i, range_val in enumerate(msg.ranges):
            if not (math.isinf(range_val) or math.isnan(range_val)) and range_val < 1.0:
                # Calculate obstacle position in robot frame
                x = range_val * math.cos(angle)
                y = range_val * math.sin(angle)
                obstacles.append((x, y))
            angle += msg.angle_increment

        self.current_context.obstacles = obstacles

    def camera_callback(self, msg):
        """Process camera image for object detection"""
        try:
            cv_image = self.bridge.imgmsg_to_cv2(msg, "bgr8")
            # In a real system, this would run object detection
            # For this example, we'll simulate object detection
            self.detected_objects = self.simulate_object_detection(cv_image)
            self.current_context.nearby_objects = [obj[0] for obj in self.detected_objects]
        except Exception as e:
            self.get_logger().error(f'Error processing camera image: {e}')

    def user_detected_callback(self, msg):
        """Handle user detection"""
        self.user_detected = msg.data

    def simulate_object_detection(self, image):
        """Simulate object detection (in real system, use actual detection)"""
        # This is a simulation - in real system, use actual object detection
        return [('chair', (1.0, 0.5)), ('table', (2.0, 1.0)), ('couch', (0.0, -1.0))]

    def voice_command_callback(self, msg):
        """Process voice command with context awareness"""
        command = msg.data.lower()
        self.get_logger().info(f'Processing command with context: {command}')

        # Publish current context
        context_msg = String()
        context_msg.data = f"Location: {self.current_context.current_location}, Objects: {self.current_context.nearby_objects}, Room: {self.current_context.room_type}"
        self.context_pub.publish(context_msg)

        # Resolve ambiguous commands using context
        resolved_command = self.resolve_ambiguous_command(command)

        resolved_msg = String()
        resolved_msg.data = resolved_command
        self.resolved_command_pub.publish(resolved_msg)

        # Execute resolved command
        self.execute_navigation_command(resolved_command)

    def resolve_ambiguous_command(self, command: str) -> str:
        """Resolve ambiguous commands using context"""
        # Handle ambiguous location references
        for ambiguous_term, specific_options in self.location_ambiguity_resolver.items():
            if ambiguous_term in command:
                # Check if any specific option is nearby
                nearby_specific = [obj for obj in specific_options if any(ambiguous_term in nearby_obj for nearby_obj in self.current_context.nearby_objects)]

                if nearby_specific:
                    # Use the first nearby specific object
                    specific_obj = nearby_specific[0]
                    resolved = command.replace(ambiguous_term, specific_obj)
                    self.get_logger().info(f'Resolved "{ambiguous_term}" to "{specific_obj}" based on context')
                    return resolved

        # Handle relative navigation commands
        if 'left' in command or 'right' in command or 'forward' in command:
            return self.resolve_relative_command(command)

        return command

    def resolve_relative_command(self, command: str) -> str:
        """Resolve relative navigation commands"""
        # Convert relative commands to absolute coordinates
        current_x, current_y, current_yaw = self.current_context.current_location

        # Default relative distances
        forward_dist = 1.0
        lateral_dist = 0.5

        if 'forward' in command or 'ahead' in command:
            target_x = current_x + forward_dist * math.cos(current_yaw)
            target_y = current_y + forward_dist * math.sin(current_yaw)
        elif 'left' in command:
            target_x = current_x + lateral_dist * math.cos(current_yaw + math.pi/2)
            target_y = current_y + lateral_dist * math.sin(current_yaw + math.pi/2)
        elif 'right' in command:
            target_x = current_x + lateral_dist * math.cos(current_yaw - math.pi/2)
            target_y = current_y + lateral_dist * math.sin(current_yaw - math.pi/2)
        else:
            return command

        # For this example, we'll return a command that indicates relative movement
        return f"goto {target_x:.2f},{target_y:.2f}"

    def execute_navigation_command(self, command: str):
        """Execute resolved navigation command"""
        if command.startswith("goto"):
            try:
                # Parse coordinates from "goto x,y" format
                coords = command[5:].split(',')
                x = float(coords[0])
                y = float(coords[1])
                self.send_navigation_goal(x, y, 0.0)
            except (ValueError, IndexError):
                self.get_logger().error(f'Invalid coordinate format: {command}')
        else:
            # Handle other commands
            self.handle_named_location(command)

    def handle_named_location(self, command: str):
        """Handle navigation to named locations"""
        # This would typically use a semantic map
        # For this example, we'll use predefined locations
        location_map = {
            'kitchen': (2.0, 2.0, 0.0),
            'living room': (0.0, 0.0, 0.0),
            'bedroom': (3.0, -1.0, 0.0),
            'office': (-2.0, 1.0, 0.0),
            'kitchen table': (2.2, 2.2, 0.0),
            'dining table': (0.5, -0.5, 0.0),
            'office desk': (-1.8, 1.2, 0.0)
        }

        for location_name, (x, y, theta) in location_map.items():
            if location_name in command:
                self.send_navigation_goal(x, y, theta)
                return

        self.get_logger().warn(f'Unknown location in command: {command}')

    def send_navigation_goal(self, x: float, y: float, theta: float = 0.0):
        """Send navigation goal"""
        goal_msg = PoseStamped()
        goal_msg.header = Header()
        goal_msg.header.stamp = self.get_clock().now().to_msg()
        goal_msg.header.frame_id = 'map'

        goal_msg.pose.position.x = x
        goal_msg.pose.position.y = y
        goal_msg.pose.position.z = 0.0

        # Convert angle to quaternion
        goal_msg.pose.orientation.z = math.sin(theta / 2.0)
        goal_msg.pose.orientation.w = math.cos(theta / 2.0)

        self.navigation_goal_pub.publish(goal_msg)
        self.get_logger().info(f'Sent navigation goal to ({x}, {y})')

    def quaternion_to_yaw(self, quat):
        """Convert quaternion to yaw angle"""
        siny_cosp = 2 * (quat.w * quat.z + quat.x * quat.y)
        cosy_cosp = 1 - 2 * (quat.y * quat.y + quat.z * quat.z)
        return math.atan2(siny_cosp, cosy_cosp)

    def get_current_context(self) -> NavigationContext:
        """Get current navigation context"""
        return self.current_context

#!/usr/bin/env python3

"""
Voice Navigation System Manager
Coordinates all voice navigation components
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool
from geometry_msgs.msg import PoseStamped
from nav2_msgs.action import NavigateToPose
from rclpy.action import ActionClient
from rclpy.qos import QoSProfile
import threading
import queue
from typing import Dict, List, Optional


class VoiceNavigationManager(Node):
    def __init__(self):
        super().__init__('voice_navigation_manager')

        # Publishers
        self.status_pub = self.create_publisher(String, 'voice_nav_status', 10)
        self.feedback_pub = self.create_publisher(String, 'voice_nav_feedback', 10)

        # Subscribers
        self.voice_command_sub = self.create_subscription(
            String, 'voice_commands', self.voice_command_callback, 10
        )
        self.navigation_status_sub = self.create_subscription(
            String, 'navigation_status', self.navigation_status_callback, 10
        )
        self.system_status_sub = self.create_subscription(
            String, 'system_status', self.system_status_callback, 10
        )

        # Action clients
        self.nav_client = ActionClient(self, NavigateToPose, 'navigate_to_pose')

        # Command processing
        self.command_queue = queue.Queue()
        self.command_thread = threading.Thread(target=self.process_commands, daemon=True)
        self.command_thread.start()

        # System state
        self.system_ready = False
        self.navigation_active = False
        self.last_command = ""
        self.command_history = []

        # Navigation parameters
        self.navigation_timeout = 30.0  # seconds
        self.retry_attempts = 3

        # Supported commands and help text
        self.supported_commands = {
            'navigation': [
                'go to [location]',
                'navigate to [location]',
                'move to [location]',
                'go to the [object]',
                'find [object]'
            ],
            'control': [
                'stop',
                'halt',
                'cancel',
                'pause',
                'resume'
            ],
            'information': [
                'where are you',
                'status',
                'help',
                'what can you do'
            ]
        }

        self.get_logger().info('Voice Navigation Manager initialized')

    def voice_command_callback(self, msg):
        """Handle voice commands"""
        command = msg.data.lower().strip()
        self.get_logger().info(f'Received voice command: {command}')

        # Update status
        status_msg = String()
        status_msg.data = f"Received: {command}"
        self.status_pub.publish(status_msg)

        # Add to command queue for processing
        self.command_queue.put(command)

        # Update command history
        self.command_history.append(command)
        if len(self.command_history) > 10:  # Keep last 10 commands
            self.command_history.pop(0)

        # Store last command
        self.last_command = command

    def navigation_status_callback(self, msg):
        """Handle navigation status updates"""
        self.get_logger().debug(f'Navigation status: {msg.data}')

        # Check if navigation is active
        self.navigation_active = 'active' in msg.data.lower()

    def system_status_callback(self, msg):
        """Handle system status updates"""
        self.system_ready = 'ready' in msg.data.lower()

    def process_commands(self):
        """Process commands in separate thread"""
        while rclpy.ok():
            try:
                command = self.command_queue.get(timeout=1.0)
                self.execute_command(command)
            except queue.Empty:
                continue
            except Exception as e:
                self.get_logger().error(f'Command processing error: {e}')

    def execute_command(self, command: str):
        """Execute a voice command"""
        self.get_logger().info(f'Executing command: {command}')

        # Categorize and execute command
        if any(keyword in command for keyword in ['go to', 'navigate to', 'move to', 'find']):
            self.handle_navigation_command(command)
        elif any(keyword in command for keyword in ['stop', 'halt', 'cancel']):
            self.handle_stop_command(command)
        elif any(keyword in command for keyword in ['where are you', 'status', 'position']):
            self.handle_status_command(command)
        elif any(keyword in command for keyword in ['help', 'what can you do', 'commands']):
            self.handle_help_command(command)
        else:
            self.handle_unknown_command(command)

    def handle_navigation_command(self, command: str):
        """Handle navigation commands"""
        if self.navigation_active:
            feedback = String()
            feedback.data = "I'm already navigating. Please wait or say 'stop' to cancel."
            self.feedback_pub.publish(feedback)
            return

        # Extract destination
        destination = self.extract_destination(command)
        if destination:
            self.get_logger().info(f'Navigating to: {destination}')

            # In a real system, this would look up the location in a semantic map
            # For this example, we'll use some predefined locations
            location_map = {
                'kitchen': (2.0, 2.0, 0.0),
                'living room': (0.0, 0.0, 0.0),
                'bedroom': (3.0, -1.0, 0.0),
                'office': (-2.0, 1.0, 0.0),
                'bathroom': (1.0, -2.0, 0.0),
                'table': (0.5, 0.5, 0.0),  # Default table location
                'chair': (1.0, 1.0, 0.0)   # Default chair location
            }

            if destination in location_map:
                x, y, theta = location_map[destination]
                success = self.send_navigation_goal(x, y, theta)

                if success:
                    feedback = String()
                    feedback.data = f"Okay, I'm going to the {destination}."
                    self.feedback_pub.publish(feedback)
                else:
                    feedback = String()
                    feedback.data = f"Sorry, I couldn't navigate to {destination}."
                    self.feedback_pub.publish(feedback)
            else:
                feedback = String()
                feedback.data = f"I don't know where {destination} is. Please specify a known location."
                self.feedback_pub.publish(feedback)
        else:
            feedback = String()
            feedback.data = "I didn't understand the destination. Please specify where to go."
            self.feedback_pub.publish(feedback)

    def handle_stop_command(self, command: str):
        """Handle stop commands"""
        if self.navigation_active:
            # In a real system, this would cancel the current navigation goal
            feedback = String()
            feedback.data = "Okay, I'm stopping navigation."
            self.feedback_pub.publish(feedback)
            self.get_logger().info('Stop command executed')
        else:
            feedback = String()
            feedback.data = "I'm not currently navigating."
            self.feedback_pub.publish(feedback)

    def handle_status_command(self, command: str):
        """Handle status/position commands"""
        feedback = String()
        feedback.data = "I am currently at the starting position in the living room."
        self.feedback_pub.publish(feedback)

    def handle_help_command(self, command: str):
        """Handle help commands"""
        help_text = "I can help you with navigation. You can say things like: "
        help_text += ", ".join(self.supported_commands['navigation'][:3])  # Show first 3 navigation commands
        help_text += ". I can also respond to stop commands like 'stop' or 'halt'."

        feedback = String()
        feedback.data = help_text
        self.feedback_pub.publish(feedback)

    def handle_unknown_command(self, command: str):
        """Handle unknown commands"""
        feedback = String()

        # Try to detect if it's a navigation command with unknown location
        if any(keyword in command for keyword in ['go', 'navigate', 'move', 'find']):
            feedback.data = f"I heard a navigation command but didn't understand the destination in '{command}'. Try saying 'Go to kitchen' or 'Find table'."
        else:
            feedback.data = f"I didn't understand '{command}'. Say 'help' to hear what I can do."

        self.feedback_pub.publish(feedback)

    def extract_destination(self, command: str) -> Optional[str]:
        """Extract destination from command"""
        # Common destination patterns
        patterns = [
            r'go to the (.+)',
            r'go to (.+)',
            r'navigate to the (.+)',
            r'navigate to (.+)',
            r'move to the (.+)',
            r'move to (.+)',
            r'find the (.+)',
            r'find (.+)'
        ]

        for pattern in patterns:
            import re
            match = re.search(pattern, command)
            if match:
                destination = match.group(1).strip()
                # Clean up the destination
                destination = destination.replace('the ', '').strip()
                return destination

        return None

    def send_navigation_goal(self, x: float, y: float, theta: float = 0.0) -> bool:
        """Send navigation goal to Nav2"""
        try:
            # Wait for action server
            if not self.nav_client.wait_for_server(timeout_sec=5.0):
                self.get_logger().error('Navigation server not available')
                return False

            # Create navigation goal
            goal_msg = NavigateToPose.Goal()
            goal_msg.pose.header.frame_id = 'map'
            goal_msg.pose.header.stamp = self.get_clock().now().to_msg()
            goal_msg.pose.pose.position.x = x
            goal_msg.pose.pose.position.y = y
            goal_msg.pose.pose.position.z = 0.0

            # Convert angle to quaternion
            import math
            goal_msg.pose.pose.orientation.z = math.sin(theta / 2.0)
            goal_msg.pose.pose.orientation.w = math.cos(theta / 2.0)

            # Send goal
            self.get_logger().info(f'Sending navigation goal to ({x}, {y})')
            future = self.nav_client.send_goal_async(goal_msg)
            future.add_done_callback(self.goal_response_callback)

            return True
        except Exception as e:
            self.get_logger().error(f'Error sending navigation goal: {e}')
            return False

    def goal_response_callback(self, future):
        """Handle navigation goal response"""
        try:
            goal_handle = future.result()
            if not goal_handle.accepted:
                self.get_logger().info('Navigation goal rejected')
                return

            self.get_logger().info('Navigation goal accepted')
            result_future = goal_handle.get_result_async()
            result_future.add_done_callback(self.get_result_callback)
        except Exception as e:
            self.get_logger().error(f'Error in goal response: {e}')

    def get_result_callback(self, future):
        """Handle navigation result"""
        try:
            result = future.result().result
            self.get_logger().info(f'Navigation completed with result: {result}')

            # Provide feedback
            feedback = String()
            feedback.data = "I have reached the destination."
            self.feedback_pub.publish(feedback)
        except Exception as e:
            self.get_logger().error(f'Error in result callback: {e}')

    def get_system_status(self) -> Dict:
        """Get current system status"""
        return {
            'system_ready': self.system_ready,
            'navigation_active': self.navigation_active,
            'last_command': self.last_command,
            'command_history_count': len(self.command_history)
        }


def main(args=None):
    rclpy.init(args=args)

    manager = VoiceNavigationManager()

    try:
        rclpy.spin(manager)
    except KeyboardInterrupt:
        manager.get_logger().info('Shutting down voice navigation manager')
    finally:
        manager.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()

### 1. Speech Recognition Challenges

- **Environmental Noise**: Background noise affects recognition accuracy
- **Speaker Variations**: Different accents, speaking styles, and vocal characteristics
- **Ambient Conditions**: Room acoustics and microphone quality
- **Real-time Processing**: Latency requirements for responsive interaction

### 2. Natural Language Understanding

- **Ambiguity Resolution**: Handling vague or ambiguous commands
- **Context Awareness**: Using environmental and situational context
- **Multi-modal Input**: Combining speech with visual and spatial information
- **Error Recovery**: Gracefully handling misrecognitions

### 3. System Integration

- **Latency Requirements**: Fast response times for natural interaction
- **Robustness**: Handling failures gracefully without system crashes
- **User Experience**: Providing clear feedback and error messages
- **Safety**: Ensuring navigation commands don't lead to unsafe situations
