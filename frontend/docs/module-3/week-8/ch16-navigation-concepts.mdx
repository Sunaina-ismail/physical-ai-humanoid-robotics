# Chapter 16: Navigation Concepts

## Introduction

Navigation is one of the most fundamental capabilities for autonomous robots, enabling them to move intelligently from one location to another while avoiding obstacles and adapting to their environment. This chapter explores the core concepts of robot navigation, including path planning, localization, mapping, and the integration of perception and control systems. Understanding these concepts is essential for developing robots that can operate autonomously in real-world environments.

## Real-World Analogy: The Human Navigation System

Think of robot navigation like how humans navigate through unfamiliar environments. When you enter a new building, you use multiple senses and cognitive processes: you observe landmarks (mapping), remember your current location (localization), plan routes to your destination (path planning), and continuously adjust your path based on obstacles and new information (replanning). Robot navigation systems work similarly, using sensors instead of human senses and algorithms instead of human cognition to achieve autonomous movement.

## Core Concepts

### 1. The Navigation Stack Components

Robot navigation typically involves three interconnected components:

- **Localization**: Determining the robot's position in the environment
- **Mapping**: Creating and maintaining a representation of the environment
- **Path Planning**: Finding optimal routes from current location to goal

### 2. Coordinate Frames in Navigation

Navigation systems rely heavily on coordinate frames and transformations:
- **map**: Global reference frame for the environment map
- **odom**: Odometry-based reference frame (drifts over time)
- **base_link**: Robot's local coordinate frame
- **laser**: Sensor-specific coordinate frame for obstacle detection

### 3. Path Planning Algorithms

Different algorithms for different scenarios:
- **Global planners**: A*, Dijkstra for optimal paths in known environments
- **Local planners**: Dynamic Window Approach (DWA), Trajectory Rollout for obstacle avoidance
- **Sampling-based**: RRT, PRM for complex environments

Let's implement a basic path planning system using the A* algorithm:

```python
#!/usr/bin/env python3

"""
Basic Path Planning Implementation
This node demonstrates A* path planning algorithm for navigation
"""

import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped, Point
from nav_msgs.msg import OccupancyGrid, Path
from sensor_msgs.msg import LaserScan
from std_msgs.msg import Header
import numpy as np
import heapq
from typing import List, Tuple, Optional


class NavigationPlanner(Node):
    def __init__(self):
        super().__init__('navigation_planner')

        # Publishers for path and visualization
        self.path_pub = self.create_publisher(Path, 'plan', 10)
        self.goal_sub = self.create_subscription(
            PoseStamped, 'goal_pose', self.goal_callback, 10
        )
        self.map_sub = self.create_subscription(
            OccupancyGrid, 'map', self.map_callback, 10
        )
        self.laser_sub = self.create_subscription(
            LaserScan, 'scan', self.laser_callback, 10
        )

        # Navigation state
        self.map_data = None
        self.map_resolution = 0.0
        self.map_width = 0
        self.map_height = 0
        self.map_origin = [0.0, 0.0, 0.0]  # x, y, theta
        self.current_goal = None
        self.current_pose = None

        self.get_logger().info('Navigation Planner initialized')

    def map_callback(self, msg):
        """Callback for receiving map data"""
        self.map_data = np.array(msg.data).reshape((msg.info.height, msg.info.width))
        self.map_resolution = msg.info.resolution
        self.map_width = msg.info.width
        self.map_height = msg.info.height
        self.map_origin = [
            msg.info.origin.position.x,
            msg.info.origin.position.y,
            msg.info.origin.orientation.z
        ]
        self.get_logger().info(f'Map received: {self.map_width}x{self.map_height}, resolution: {self.map_resolution}')

    def laser_callback(self, msg):
        """Callback for laser scan data"""
        # Update current pose based on laser data (simplified)
        # In practice, this would come from localization system
        pass

    def goal_callback(self, msg):
        """Callback for receiving navigation goal"""
        self.current_goal = msg.pose
        self.get_logger().info(f'Received goal: ({msg.pose.position.x}, {msg.pose.position.y})')

        # Plan path if map is available
        if self.map_data is not None:
            self.plan_path()

    def world_to_map(self, x_world, y_world):
        """Convert world coordinates to map coordinates"""
        x_map = int((x_world - self.map_origin[0]) / self.map_resolution)
        y_map = int((y_world - self.map_origin[1]) / self.map_resolution)
        return x_map, y_map

    def map_to_world(self, x_map, y_map):
        """Convert map coordinates to world coordinates"""
        x_world = x_map * self.map_resolution + self.map_origin[0]
        y_world = y_map * self.map_resolution + self.map_origin[1]
        return x_world, y_world

    def is_valid_cell(self, x, y):
        """Check if cell is valid (not occupied or out of bounds)"""
        if x < 0 or x >= self.map_width or y < 0 or y >= self.map_height:
            return False
        # Check if cell is occupied (value > 50 means obstacle in OccupancyGrid)
        return self.map_data[y, x] < 50

    def heuristic(self, a, b):
        """Heuristic function for A* (Manhattan distance)"""
        return abs(a[0] - b[0]) + abs(a[1] - b[1])

    def a_star(self, start, goal):
        """A* path planning algorithm"""
        if not self.is_valid_cell(start[0], start[1]) or not self.is_valid_cell(goal[0], goal[1]):
            self.get_logger().warn('Start or goal is in invalid cell')
            return None

        # Priority queue: (f_score, g_score, x, y)
        frontier = [(0, 0, start[0], start[1])]
        came_from = {}
        cost_so_far = {}
        came_from[(start[0], start[1])] = None
        cost_so_far[(start[0], start[1])] = 0

        # 4-directional movement (up, down, left, right)
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        while frontier:
            _, current_g, x, y = heapq.heappop(frontier)
            current = (x, y)

            # Check if we reached the goal
            if current == goal:
                break

            # Explore neighbors
            for dx, dy in directions:
                next_cell = (x + dx, y + dy)

                if self.is_valid_cell(next_cell[0], next_cell[1]):
                    new_cost = cost_so_far[current] + 1  # Simple cost of 1 per step

                    if next_cell not in cost_so_far or new_cost < cost_so_far[next_cell]:
                        cost_so_far[next_cell] = new_cost
                        priority = new_cost + self.heuristic(next_cell, goal)
                        heapq.heappush(frontier, (priority, new_cost, next_cell[0], next_cell[1]))
                        came_from[next_cell] = current

        # Reconstruct path
        if goal not in came_from:
            return None  # No path found

        path = []
        current = goal
        while current != start:
            path.append(current)
            current = came_from[current]
        path.append(start)
        path.reverse()

        return path

    def plan_path(self):
        """Plan path from current position to goal"""
        if self.current_goal is None:
            self.get_logger().warn('No goal set')
            return

        # Convert goal to map coordinates
        goal_x, goal_y = self.world_to_map(
            self.current_goal.position.x,
            self.current_goal.position.y
        )

        # For this example, assume current position is at (0,0) in map coordinates
        start_x, start_y = self.world_to_map(0.0, 0.0)

        # Plan path using A*
        path = self.a_star((start_x, start_y), (goal_x, goal_y))

        if path is None:
            self.get_logger().warn('No path found to goal')
            return

        # Convert path back to world coordinates and create Path message
        path_msg = Path()
        path_msg.header = Header()
        path_msg.header.stamp = self.get_clock().now().to_msg()
        path_msg.header.frame_id = 'map'

        for x_map, y_map in path:
            x_world, y_world = self.map_to_world(x_map, y_map)
            pose = PoseStamped()
            pose.header = Header()
            pose.header.stamp = self.get_clock().now().to_msg()
            pose.header.frame_id = 'map'
            pose.pose.position.x = x_world
            pose.pose.position.y = y_world
            pose.pose.position.z = 0.0
            pose.pose.orientation.w = 1.0  # No rotation

            path_msg.poses.append(pose)

        # Publish the path
        self.path_pub.publish(path_msg)
        self.get_logger().info(f'Published path with {len(path_msg.poses)} waypoints')


def main(args=None):
    rclpy.init(args=args)

    navigation_planner = NavigationPlanner()

    try:
        rclpy.spin(navigation_planner)
    except KeyboardInterrupt:
        navigation_planner.get_logger().info('Shutting down navigation planner')
    finally:
        navigation_planner.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Navigation System Integration

Now let's create a navigation manager that integrates perception and planning:

```python
#!/usr/bin/env python3

"""
Navigation System Manager
Integrates localization, mapping, and path planning components
"""

import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped, Twist
from nav_msgs.msg import Odometry, Path
from sensor_msgs.msg import LaserScan
from std_msgs.msg import Bool
import numpy as np
from tf2_ros import TransformListener, Buffer
import tf2_geometry_msgs
from typing import Optional


class NavigationManager(Node):
    def __init__(self):
        super().__init__('navigation_manager')

        # Create TF2 buffer and listener
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, self)

        # Publishers and subscribers
        self.cmd_vel_pub = self.create_publisher(Twist, 'cmd_vel', 10)
        self.goal_sub = self.create_subscription(
            PoseStamped, 'move_base_simple/goal', self.goal_callback, 10
        )
        self.odom_sub = self.create_subscription(
            Odometry, 'odom', self.odom_callback, 10
        )
        self.laser_sub = self.create_subscription(
            LaserScan, 'scan', self.laser_callback, 10
        )
        self.path_sub = self.create_subscription(
            Path, 'plan', self.path_callback, 10
        )

        # Navigation state
        self.current_goal = None
        self.current_path = None
        self.current_pose = None
        self.navigation_active = False
        self.path_index = 0

        # Navigation parameters
        self.linear_speed = 0.2  # m/s
        self.angular_speed = 0.5  # rad/s
        self.arrival_threshold = 0.2  # meters
        self.path_lookahead = 0.5  # meters ahead on path

        # Timer for navigation control
        self.nav_timer = self.create_timer(0.1, self.navigation_control)

        self.get_logger().info('Navigation Manager initialized')

    def goal_callback(self, msg):
        """Handle navigation goal"""
        self.current_goal = msg
        self.get_logger().info(f'New goal received: ({msg.pose.position.x}, {msg.pose.position.y})')

        # Start navigation
        self.navigation_active = True
        self.path_index = 0

    def odom_callback(self, msg):
        """Handle odometry data"""
        self.current_pose = msg.pose.pose

    def laser_callback(self, msg):
        """Handle laser scan for obstacle detection"""
        if not self.navigation_active:
            return

        # Check for obstacles in front of robot
        min_distance = min(msg.ranges)

        if min_distance < 0.5:  # Obstacle within 0.5m
            self.get_logger().warn('Obstacle detected, stopping navigation')
            self.stop_robot()
            # In a real system, this would trigger replanning

    def path_callback(self, msg):
        """Handle received path"""
        if len(msg.poses) > 0:
            self.current_path = msg.poses
            self.path_index = 0
            self.get_logger().info(f'Received path with {len(msg.poses)} waypoints')

    def get_current_position(self):
        """Get current position in map frame"""
        if self.current_pose is None:
            return None

        # In a real system, this would use TF2 to get the transform
        # For this example, we'll use the pose directly
        return self.current_pose.position

    def navigation_control(self):
        """Main navigation control loop"""
        if not self.navigation_active or self.current_path is None:
            return

        if self.path_index >= len(self.current_path):
            self.get_logger().info('Reached end of path')
            self.navigation_active = False
            self.stop_robot()
            return

        # Get current position and next waypoint
        current_pos = self.get_current_position()
        if current_pos is None:
            return

        target_pose = self.current_path[self.path_index].pose
        target_pos = target_pose.position

        # Calculate distance to target
        dist_to_target = np.sqrt(
            (current_pos.x - target_pos.x)**2 +
            (current_pos.y - target_pos.y)**2
        )

        # Check if we've reached the current waypoint
        if dist_to_target < self.arrival_threshold:
            self.path_index += 1
            if self.path_index >= len(self.current_path):
                self.get_logger().info('Reached goal')
                self.navigation_active = False
                self.stop_robot()
                return

        # Calculate direction to target
        dx = target_pos.x - current_pos.x
        dy = target_pos.y - current_pos.y
        target_angle = np.arctan2(dy, dx)

        # Get current robot orientation
        current_yaw = self.quaternion_to_yaw(self.current_pose.orientation)

        # Calculate angle difference
        angle_diff = target_angle - current_yaw
        # Normalize angle to [-pi, pi]
        while angle_diff > np.pi:
            angle_diff -= 2 * np.pi
        while angle_diff < -np.pi:
            angle_diff += 2 * np.pi

        # Create velocity command
        cmd_vel = Twist()

        # If angle is large, turn first
        if abs(angle_diff) > 0.2:  # 0.2 rad = ~11 degrees
            cmd_vel.angular.z = np.clip(angle_diff * 2.0, -self.angular_speed, self.angular_speed)
        else:
            # Move forward while adjusting orientation
            cmd_vel.linear.x = self.linear_speed
            cmd_vel.angular.z = np.clip(angle_diff * 3.0, -self.angular_speed, self.angular_speed)

        # Publish command
        self.cmd_vel_pub.publish(cmd_vel)

    def quaternion_to_yaw(self, quat):
        """Convert quaternion to yaw angle"""
        siny_cosp = 2 * (quat.w * quat.z + quat.x * quat.y)
        cosy_cosp = 1 - 2 * (quat.y * quat.y + quat.z * quat.z)
        return np.arctan2(siny_cosp, cosy_cosp)

    def stop_robot(self):
        """Stop the robot"""
        cmd_vel = Twist()
        self.cmd_vel_pub.publish(cmd_vel)
        self.get_logger().info('Robot stopped')


def main(args=None):
    rclpy.init(args=args)

    navigation_manager = NavigationManager()

    try:
        rclpy.spin(navigation_manager)
    except KeyboardInterrupt:
        navigation_manager.get_logger().info('Shutting down navigation manager')
    finally:
        navigation_manager.stop_robot()
        navigation_manager.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Key Navigation Concepts

### 1. Localization vs Mapping vs Navigation

- **Localization**: Determining where the robot is in a known map
- **Mapping**: Creating a map of an unknown environment
- **Navigation**: Planning and executing paths to reach goals

### 2. Coordinate Frame Management

Navigation systems require careful management of coordinate frames:
- Transform trees must be properly maintained
- Time synchronization is critical
- TF2 provides essential tools for frame transformations

### 3. Safety and Obstacle Avoidance

- Local planners must react to dynamic obstacles
- Collision checking and emergency stopping
- Path replanning when obstacles are detected
