## Why This Matters

Navigation2 (Nav2) is the standard navigation stack for ROS 2, providing complete autonomous navigation capabilities including localization, path planning, and obstacle avoidance. Deploying Nav2 on edge platforms like NVIDIA Jetson enables autonomous robots to operate in real-world environments with resource constraints. Understanding how to optimize Nav2 for edge computing is essential for robotics engineers working on deployable systems.

**Real-World Applications**:
- **Warehouse Robots**: Autonomous inventory management and material transport
- **Service Robots**: Indoor navigation for delivery, cleaning, and assistance
- **Agricultural Robots**: Autonomous navigation between crop rows
- **Search and Rescue**: GPS-denied navigation in disaster zones

:::danger Hardware Safety
Before deploying navigation systems on Jetson hardware:
- Ensure emergency stop mechanisms are in place and accessible
- Verify robot's maximum speed and acceleration parameters are safe
- Test navigation algorithms in controlled environments before deployment
- Implement Dead Man Switch patterns with 100ms timeout for motor control
:::

    """Assess LiDAR data quality for navigation safety."""
    # Calculate percentage of valid readings
    valid_readings = sum(1 for r in scan_msg.ranges if 0.1 < r < 10.0)
    total_readings = len(scan_msg.ranges)

    quality_ratio = valid_readings / total_readings if total_readings > 0 else 0

def detect_obstacles_jetson_optimized(scan_msg, min_distance=0.5):
    """Efficient obstacle detection optimized for Jetson."""
    # Use numpy for efficient processing
    ranges_array = np.array(scan_msg.ranges)

    # Filter valid ranges
    valid_mask = (ranges_array > 0.1) & (ranges_array < min_distance)
    close_obstacles = ranges_array[valid_mask]

    # Count obstacles in different sectors for navigation decisions
    angle_increment = scan_msg.angle_increment
    num_sectors = 8
    sector_size = len(ranges_array) // num_sectors

    sector_obstacles = []
    for i in range(num_sectors):
        start_idx = i * sector_size
        end_idx = start_idx + sector_size if i < num_sectors - 1 else len(ranges_array)

### Safety Node for Navigation

```python
#!/usr/bin/env python3
"""
Jetson Navigation Safety Node

Implements safety mechanisms including Dead Man Switch pattern for
navigation on Jetson platforms. Includes emergency stop and
timeout-based safety controls.
"""

import rclpy
from rclpy.node import Node
from rclpy.qos import QoSProfile, QoSHistoryPolicy, QoSReliabilityPolicy
from geometry_msgs.msg import Twist, PoseStamped
from sensor_msgs.msg import LaserScan
from std_msgs.msg import Bool
import time
from threading import Lock


class JetsonNavigationSafety(Node):
    """Safety node for Jetson navigation with Dead Man Switch implementation."""

    def __init__(self):
        super().__init__('jetson_navigation_safety')

        # Safety parameters
        self.declare_parameter('deadman_timeout', 0.1)  # 100ms timeout
        self.declare_parameter('emergency_distance', 0.3)  # Emergency stop distance
        self.declare_parameter('safety_enabled', True)

        self.deadman_timeout = self.get_parameter('deadman_timeout').value
        self.emergency_distance = self.get_parameter('emergency_distance').value
        self.safety_enabled = self.get_parameter('safety_enabled').value

        # Create QoS profile
        qos_profile = QoSProfile(
            history=QoSHistoryPolicy.KEEP_LAST,
            depth=1,
            reliability=QoSReliabilityPolicy.BEST_EFFORT,
        )

        # Create subscribers
        self.cmd_vel_sub = self.create_subscription(
            Twist,
            '/cmd_vel',
            self.cmd_vel_callback,
            qos_profile
        )

        self.lidar_sub = self.create_subscription(
            LaserScan,
            '/jetson/lidar/scan',
            self.lidar_callback,
            qos_profile
        )

        # Create publishers
        self.safety_cmd_pub = self.create_publisher(Twist, '/safety_cmd_vel', qos_profile)
        self.emergency_stop_pub = self.create_publisher(Bool, '/emergency_stop', qos_profile)

        # Safety state
        self.last_cmd_time = self.get_clock().now()
        self.last_cmd_vel = Twist()
        self.obstacle_detected = False
        self.safety_lock = Lock()

        # Timer for safety checks
        self.safety_timer = self.create_timer(0.05, self.safety_check)  # 20 Hz safety checks

        self.get_logger().info('Jetson Navigation Safety node started')

    def cmd_vel_callback(self, msg):
        """Handle incoming velocity commands with safety processing."""
        with self.safety_lock:
            self.last_cmd_vel = msg
            self.last_cmd_time = self.get_clock().now()

    def lidar_callback(self, msg):
        """Process LiDAR data for obstacle detection."""
        # Check for obstacles in critical directions
        min_distance = float('inf')

        # Check forward sector (simplified)
        forward_start = len(msg.ranges) // 2 - 10
        forward_end = len(msg.ranges) // 2 + 10

        if 0 <= forward_start < len(msg.ranges) and 0 <= forward_end < len(msg.ranges):
            forward_ranges = msg.ranges[forward_start:forward_end]
            valid_ranges = [r for r in forward_ranges if 0.01 < r < 10.0]

            if valid_ranges:
                min_distance = min(valid_ranges)

        with self.safety_lock:
            self.obstacle_detected = min_distance < self.emergency_distance

    def safety_check(self):
        """Perform safety checks at high frequency."""
        current_time = self.get_clock().now()

        with self.safety_lock:
            # Check Dead Man Switch timeout
            time_since_last_cmd = (current_time - self.last_cmd_time).nanoseconds / 1e9

            # Determine if command should be passed through
            if (time_since_last_cmd > self.deadman_timeout or
                self.obstacle_detected or
                not self.safety_enabled):

                # Send stop command
                stop_cmd = Twist()
                self.safety_cmd_pub.publish(stop_cmd)

                # Publish emergency stop signal
                emergency_msg = Bool()
                emergency_msg.data = True
                self.emergency_stop_pub.publish(emergency_msg)

                if time_since_last_cmd > self.deadman_timeout:
                    self.get_logger().warn('Dead Man Switch timeout - stopping robot')
                elif self.obstacle_detected:
                    self.get_logger().warn('Obstacle detected - emergency stop')
            else:
                # Pass through the command
                self.safety_cmd_pub.publish(self.last_cmd_vel)

    def destroy_node(self):
        """Ensure robot stops when node is destroyed."""
        stop_cmd = Twist()
        self.safety_cmd_pub.publish(stop_cmd)
        super().destroy_node()


def main(args=None):
    rclpy.init(args=args)

    node = JetsonNavigationSafety()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Shutting down safety node')
    finally:
        # Ensure robot stops
        stop_cmd = Twist()
        node.safety_cmd_pub.publish(stop_cmd)
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Performance Monitoring and Tuning

### Jetson-Specific Monitoring

```bash
# Monitor system resources during navigation
sudo tegrastats  # Real-time CPU/GPU/memory usage
jtop            # Jetson system monitor

# Monitor ROS 2 navigation performance
ros2 topic hz /cmd_vel                    # Check command frequency
ros2 run tf2_tools view_frames            # Check transform quality
ros2 run rqt_plot rqt_plot                # Plot navigation metrics
```

### Parameter Tuning Guidelines

**For Resource-Constrained Performance**:
- Reduce costmap resolution (0.05m → 0.1m)
- Lower update frequencies (10Hz → 5Hz)
- Reduce costmap size (10x10m → 5x5m)
- Limit particle counts in AMCL (100 → 50)

**For Safety and Reliability**:
- Maintain conservative obstacle inflation (0.5m)
- Keep emergency stop distances appropriate (0.3m minimum)
- Use reliable QoS settings for critical topics
- Implement proper timeout mechanisms

## Troubleshooting Common Issues

### Performance Issues

**Problem**: Nav2 running slowly or timing out on Jetson
**Solutions**:
- Reduce costmap resolution and size
- Lower update frequencies in configuration
- Use TEB local planner instead of default DWB
- Monitor with `tegrastats` to identify bottlenecks

### Localization Problems

**Problem**: Robot losing localization frequently
**Solutions**:
- Ensure adequate lighting and visual features in environment
- Verify LiDAR calibration and mounting
- Adjust AMCL parameters for your environment
- Check odometry quality and consistency

### Navigation Failures

**Problem**: Robot getting stuck or failing to navigate
**Solutions**:
- Verify costmap inflation parameters
- Check for proper transform frames (tf tree)
- Ensure adequate LiDAR coverage
- Adjust local planner parameters for robot dynamics
