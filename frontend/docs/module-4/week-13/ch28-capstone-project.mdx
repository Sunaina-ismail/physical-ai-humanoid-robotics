## Project Overview: Voice-to-Action Pipeline

### System Goal

Build a robot system that accepts **natural language voice commands** and executes **multi-step navigation and manipulation tasks** autonomously.

**Example Interaction**:

**Human**: "Go to the kitchen table, pick up the blue block, and place it on the red shelf."

**Robot**:
1. Transcribes speech → text using Whisper
2. Parses task into steps using LLM task planner:
   - Step 1: Navigate to "kitchen table" waypoint
   - Step 2: Detect "blue block" using object detection
   - Step 3: Pick up block (grasp action)
   - Step 4: Navigate to "red shelf" waypoint
   - Step 5: Place block (release action)
3. Executes each step using ROS 2 action clients (Nav2 for navigation, arm controller for manipulation)
4. Reports status: "Task completed successfully" or "Failed at Step 3: Object not detected"

#### Step 1.1: Define System Requirements

**Functional Requirements** (what the system must do):
1. Accept voice command as input (from .wav file or text file)
2. Transcribe speech to text with `>85%` accuracy (using Whisper or text bypass)
3. Parse task into navigation + manipulation steps
4. Navigate to waypoints using Nav2 with `<5%` collision rate
5. Detect target objects with `>80%` accuracy
6. Execute grasp and place actions
7. Report task success/failure to user

**Non-Functional Requirements** (performance, usability):
1. End-to-end latency: `<30` seconds from command to action start
2. System uptime: `>90%` (nodes don't crash during normal operation)
3. Code quality: PEP 8 compliant, docstrings for all functions
4. Documentation: README with setup instructions, architecture diagram

**Recommended Node Responsibilities**:

1. **`voice_listener_node`**:
   - Reads .wav file or text input
   - Calls Whisper API (or uses text bypass)
   - Publishes transcribed text to `/voice_command` (std_msgs/String)

2. **`task_planner_node`**:
   - Subscribes to `/voice_command`
   - Sends command to LLM (OpenAI API, Ollama local, or rule-based parser)
   - Publishes structured task plan to `/task_plan` (custom TaskList message)

3. **`task_executor_node`** (State Machine):
   - Subscribes to `/task_plan`
   - Implements state machine: IDLE → NAVIGATE → DETECT → GRASP → PLACE → DONE
   - Calls action servers (Nav2, arm controller)
   - Publishes status updates

4. **`navigation_client_node`**:
   - Provides Nav2 action client interface
   - Accepts goal poses, monitors navigation progress
   - Reports success/failure

5. **`object_detector_node`**:
   - Subscribes to `/camera/image_raw`
   - Detects objects by color (HSV thresholding for Tier A)
   - Publishes bounding boxes + 3D positions to `/detected_objects`

6. **`manipulation_node`**:
   - Controls arm joint trajectory controller
   - Controls gripper (open/close)
   - Implements simple top-down grasp planner

**Optional**: Merge some nodes if you prefer fewer processes (e.g., task_planner + task_executor in one node).

```python
#!/usr/bin/env python3
"""
Voice Listener Node (Tier A: Text Input)

Reads voice commands from a text file and publishes them to /voice_command topic.
For Tier B/C, replace with actual Whisper speech recognition.

Published Topics:
  /voice_command (std_msgs/String): Transcribed voice commands

Parameters:
  command_file (string): Path to text file with commands (default: "commands.txt")
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class VoiceListenerNode(Node):
    """Simulates voice input by reading from text file."""

    def __init__(self):
        super().__init__('voice_listener')

        # Declare parameters
        self.declare_parameter('command_file', 'commands.txt')
        self.command_file = self.get_parameter('command_file').value

        # Publisher for voice commands
        self.publisher = self.create_publisher(String, '/voice_command', 10)

        # Timer to check for new commands
        self.timer = self.create_timer(2.0, self.check_for_command)

        self.get_logger().info(f'Voice Listener started. Monitoring {self.command_file}')
        self.last_command = ""

    def check_for_command(self):
        """Read command from file and publish if changed."""
        try:
            with open(self.command_file, 'r') as f:
                command = f.read().strip()

            if command and command != self.last_command:
                msg = String()
                msg.data = command
                self.publisher.publish(msg)
                self.get_logger().info(f'Published command: "{command}"')
                self.last_command = command

        except FileNotFoundError:
            self.get_logger().warn(f'Command file not found: {self.command_file}')


def main(args=None):
    rclpy.init(args=args)
    node = VoiceListenerNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

```python
#!/usr/bin/env python3
"""
Task Planner Node (Rule-Based Parser for Tier A)

Parses simple voice commands into structured task plans.
Recognizes patterns like:
  - "Go to X" → Navigate action
  - "Pick up X" → Navigate + Detect + Grasp sequence
  - "Place X on Y" → Navigate + Place sequence

For more complex parsing, use LLM (OpenAI, Ollama) in Tier B/C.
"""

import re
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
# Assuming you've created custom messages:
# from capstone_interfaces.msg import TaskList, TaskStep


class TaskPlannerNode(Node):
    """Rule-based parser for simple voice commands."""

    def __init__(self):
        super().__init__('task_planner')

        # Subscriber to voice commands
        self.subscription = self.create_subscription(
            String,
            '/voice_command',
            self.command_callback,
            10
        )

        # Publisher for task plans
        # For demo, publishing as String. Replace with TaskList message.
        self.publisher = self.create_publisher(String, '/task_plan', 10)

        # Define location synonyms
        self.locations = {
            'table': 'table',
            'kitchen table': 'table',
            'shelf': 'shelf',
            'red shelf': 'shelf',
            'charging station': 'charging_station',
        }

        # Define object synonyms
        self.objects = {
            'blue block': 'blue_block',
            'red block': 'red_block',
            'green block': 'green_block',
        }

        self.get_logger().info('Task Planner Node started (rule-based mode)')

    def command_callback(self, msg):
        """Parse voice command and publish task plan."""
        command = msg.data.lower()
        self.get_logger().info(f'Parsing command: "{command}"')

        # Parse command into task steps
        task_plan = self.parse_command(command)

        if task_plan:
            # For demo: publish as formatted string
            # TODO: Replace with proper TaskList message
            plan_msg = String()
            plan_msg.data = task_plan
            self.publisher.publish(plan_msg)
            self.get_logger().info(f'Published task plan: {task_plan}')
        else:
            self.get_logger().error(f'Failed to parse command: "{command}"')

    def parse_command(self, command):
        """
        Simple regex-based parser.

        Patterns:
          - "go to X" → navigate(X)
          - "pick up X" → navigate(X location), detect(X), grasp(X)
          - "place X on Y" → navigate(Y), place(X, Y)
        """

        # Pattern 1: "go to X"
        match = re.search(r'go to (?:the )?(\w+(?:\s\w+)?)', command)
        if match:
            location = match.group(1)
            if location in self.locations:
                return f"navigate:{self.locations[location]}"

        # Pattern 2: "pick up X"
        match = re.search(r'pick up (?:the )?(\w+(?:\s\w+)?)', command)
        if match:
            object_name = match.group(1)
            if object_name in self.objects:
                # Assume object is at "table" for simplicity
                return f"navigate:table;detect:{self.objects[object_name]};grasp:{self.objects[object_name]}"

        # Pattern 3: "place X on Y"
        match = re.search(r'place (?:the )?(\w+(?:\s\w+)?) on (?:the )?(\w+(?:\s\w+)?)', command)
        if match:
            object_name = match.group(1)
            location = match.group(2)
            if object_name in self.objects and location in self.locations:
                return f"navigate:{self.locations[location]};place:{self.objects[object_name]}"

        # Pattern 4: Combined "go to X, pick up Y, place on Z"
        # (Add more patterns as needed)

        return None  # Failed to parse


def main(args=None):
    rclpy.init(args=args)
    node = TaskPlannerNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

```python
Object Detector Node (Tier A: Color-Based Detection)

Detects colored blocks (red, blue, green) using HSV color thresholding.
For Tier B/C, replace with YOLO or OpenVLA for robust object detection.

Subscribed Topics:
  /camera/image_raw (sensor_msgs/Image): RGB camera images

Published Topics:
  /detected_objects (String): Detected object names and positions (simplified for Tier A)
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from std_msgs.msg import String
from cv_bridge import CvBridge
import cv2
import numpy as np


class ObjectDetectorNode(Node):
    """Color-based object detector for simulated environment."""

    def __init__(self):
        super().__init__('object_detector')

        self.bridge = CvBridge()

        # Subscriber to camera images
        self.subscription = self.create_subscription(
            Image,
            '/camera/image_raw',
            self.image_callback,
            10
        )

        # Publisher for detected objects
        self.publisher = self.create_publisher(String, '/detected_objects', 10)

        # HSV color ranges for object detection
        self.color_ranges = {
            'blue_block': {
                'lower': np.array([100, 150, 50]),   # H, S, V
                'upper': np.array([130, 255, 255])
            },
            'red_block': {
                'lower': np.array([0, 150, 50]),
                'upper': np.array([10, 255, 255])
            },
            'green_block': {
                'lower': np.array([40, 150, 50]),
                'upper': np.array([80, 255, 255])
            }
        }

        self.get_logger().info('Object Detector Node started (color-based mode)')

    def image_callback(self, msg):
        """Process camera image and detect colored objects."""
        try:
            # Convert ROS Image to OpenCV format
            cv_image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='bgr8')

            # Convert BGR to HSV
            hsv_image = cv2.cvtColor(cv_image, cv2.COLOR_BGR2HSV)

            detected_objects = []

            # Detect each color
            for object_name, color_range in self.color_ranges.items():
                mask = cv2.inRange(hsv_image, color_range['lower'], color_range['upper'])

                # Find contours
                contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

                if contours:
                    # Find largest contour
                    largest_contour = max(contours, key=cv2.contourArea)
                    area = cv2.contourArea(largest_contour)

                    # Threshold for minimum object size (avoid noise)
                    if area > 500:  # pixels
                        # Get center of object
                        M = cv2.moments(largest_contour)
                        if M['m00'] > 0:
                            cx = int(M['m10'] / M['m00'])
                            cy = int(M['m01'] / M['m00'])

                            detected_objects.append(f"{object_name} at pixel ({cx}, {cy})")

            # Publish detected objects
            if detected_objects:
                detection_msg = String()
                detection_msg.data = "; ".join(detected_objects)
                self.publisher.publish(detection_msg)
                self.get_logger().info(f'Detected: {detection_msg.data}')

        except Exception as e:
            self.get_logger().error(f'Image processing error: {e}')


def main(args=None):
    rclpy.init(args=args)
    node = ObjectDetectorNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

```python
"""
Task Executor Node - State Machine Orchestrator

States:
  - IDLE: Waiting for new task
  - PLANNING: Processing task plan

        """Receive new task plan."""
        if self.state == TaskState.IDLE:
            self.current_plan = msg.data.split(';')  # Parse simple plan format
            self.current_step_index = 0
            self.state = TaskState.PLANNING
            self.get_logger().info(f'Received task plan: {self.current_plan}')
        else:
            self.get_logger().warn('Ignoring new plan - task already in progress')

    def detection_callback(self, msg):
        """Receive detected objects."""
        self.detected_objects = msg.data.split(';')

    def state_machine_update(self):
        """Main state machine loop."""

        if self.state == TaskState.IDLE:
            # Waiting for task
            pass

        elif self.state == TaskState.PLANNING:
            # Start executing first step
            if self.current_plan and len(self.current_plan) > 0:
                self.execute_current_step()
            else:
                self.state = TaskState.FAILED
                self.get_logger().error('Empty task plan')

        elif self.state == TaskState.NAVIGATING:
            # Check navigation status (TODO: implement action client feedback)
            # For now, simulate success after delay
            self.get_logger().info('Navigating... (simulated)')
            self.advance_to_next_step()

        elif self.state == TaskState.DETECTING:
            # Check if target object detected
            if self.detected_objects:
                self.get_logger().info(f'Objects detected: {self.detected_objects}')
                self.advance_to_next_step()
            else:
                self.get_logger().info('Waiting for object detection...')

        elif self.state == TaskState.GRASPING:
            # Execute grasp (TODO: implement arm controller)
            self.get_logger().info('Grasping... (simulated)')
            self.advance_to_next_step()

        elif self.state == TaskState.PLACING:
            # Execute place (TODO: implement arm controller)
            self.get_logger().info('Placing... (simulated)')
            self.state = TaskState.SUCCESS

        elif self.state == TaskState.SUCCESS:
            self.get_logger().info('✅ Task completed successfully!')
            self.state = TaskState.IDLE
            self.current_plan = None

        elif self.state == TaskState.FAILED:
            self.get_logger().error('❌ Task failed')
            self.state = TaskState.IDLE
            self.current_plan = None

    def execute_current_step(self):
        """Execute the current step in the task plan."""
        if self.current_step_index >= len(self.current_plan):
            self.state = TaskState.SUCCESS
            return

        step = self.current_plan[self.current_step_index]
        action, target = step.split(':') if ':' in step else (step, '')

        self.get_logger().info(f'Executing step {self.current_step_index + 1}: {action} → {target}')

        if action == 'navigate':
            self.navigate_to_waypoint(target)
        elif action == 'detect':
            self.detect_object(target)
        elif action == 'grasp':
            self.grasp_object(target)
        elif action == 'place':
            self.place_object(target)
        else:
            self.get_logger().error(f'Unknown action: {action}')
            self.state = TaskState.FAILED

    def navigate_to_waypoint(self, waypoint_name):
        """Navigate to named waypoint."""
        if waypoint_name in self.waypoints:

            self.state = TaskState.FAILED
```

## Troubleshooting Guide

### Common Issues and Solutions

#### Issue 1: Gazebo won't launch

**Symptoms**: Error like `[gazebo-1] process has died`

**Solutions**:
- Check world file syntax: `gz sdf -k worlds/capstone_world.world`
- Verify Gazebo installation: `gazebo --version`
- Check for missing plugins in URDF

#### Issue 2: Nav2 navigation fails

**Symptoms**: Robot spins in place or doesn't move

**Solutions**:
- Verify map is loaded: `ros2 topic echo /map` (should show occupancy grid)
- Check robot localization: `ros2 topic echo /amcl_pose`
- Inspect costmaps in RViz: Add `/local_costmap/costmap` and `/global_costmap/costmap`
- Verify TF tree: `ros2 run tf2_tools view_frames`

#### Issue 3: Object detection doesn't find objects

**Symptoms**: `/detected_objects` topic is empty

**Solutions**:
- Verify camera is publishing: `ros2 topic hz /camera/image_raw`
- Check camera image in RViz: Add `Image` display subscribed to `/camera/image_raw`
- Tune HSV color ranges (use `cv2.imshow()` to debug HSV mask)
- Ensure objects are in camera field of view

#### Issue 4: Task executor stuck in state

**Symptoms**: State machine doesn't advance

**Solutions**:
- Add debug logging to state machine callback
- Check if action servers are running: `ros2 action list`
- Verify topic connections: `rqt_graph`
- Use `ros2 topic echo` to verify messages are being published

#### Issue 5: Arm controller doesn't move

**Symptoms**: Gripper or arm joints don't respond

**Solutions**:
- Check controller status: `ros2 control list_controllers`
- Verify joint state publisher: `ros2 topic echo /joint_states`
- Inspect URDF transmission tags (required for Gazebo control)
- Check controller configuration in `robot_controllers.yaml`
