# Chapter 24: Vision-Language-Action Paradigm

## Introduction

Vision-Language-Action (VLA) systems represent a paradigm shift in robotics, moving away from traditional modular approaches toward end-to-end trainable models that can interpret natural language commands and directly generate robot actions. Unlike classical robotics stacks that separate perception, planning, and control, VLA models learn to map visual inputs and language instructions directly to robot actions, enabling unprecedented flexibility and generalization capabilities.

This chapter introduces the foundational concepts of VLA systems, their advantages over traditional approaches, and the challenges they present in terms of training, deployment, and safety.

## Learning Objectives

By the end of this chapter, you will be able to:
- Explain the Vision-Language-Action architecture and its components
- Understand the advantages of end-to-end VLA systems over modular robotics approaches
- Implement basic VLA inference for simple robot control tasks
- Identify key challenges in VLA deployment and safety considerations
- Compare different VLA approaches and their trade-offs

## Real-World Analogy: The Multimodal Brain

Think of VLA systems like the human brain's ability to integrate multiple sensory inputs (vision, hearing) with language understanding to produce coordinated actions. When you hear "Pick up the red cup on the left," your brain simultaneously processes the visual scene, interprets the language command, and coordinates your hand movement to execute the action. VLA systems aim to replicate this seamless integration in artificial systems, learning the relationships between visual perception, language, and action from large datasets of human demonstrations.

## Core Concepts

### 1. Multimodal Integration

VLA systems combine three key modalities:
- **Vision**: Camera imagery, depth data, or other visual sensors
- **Language**: Natural language commands, questions, or descriptions
- **Action**: Robot motor commands, joint positions, or end-effector poses

### 2. End-to-End Learning

Unlike traditional robotics that decompose tasks into separate perception, planning, and control modules, VLA systems learn the entire mapping from input to output jointly:
- **Perception**: Visual features extracted from images
- **Language Understanding**: Semantic interpretation of commands
- **Action Generation**: Direct mapping to robot control commands

### 3. Generalization Capabilities

VLA systems exhibit remarkable generalization abilities:
- **Zero-shot Transfer**: Perform tasks not seen during training
- **Cross-Embodiment**: Transfer policies across different robot platforms
- **Novel Object Interaction**: Manipulate previously unseen objects

```python
#!/usr/bin/env python3

"""
Vision-Language-Action Model Implementation
Basic VLA model for end-to-end robot control
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, JointState
from geometry_msgs.msg import Twist, Pose
from std_msgs.msg import String, Float64MultiArray
from cv_bridge import CvBridge
from typing import List, Tuple, Dict, Optional
import torch
import numpy as np
import math


class VLAModel(Node):
    def __init__(self):
        super().__init__('vla_model')

        # CV Bridge for image processing
        self.bridge = CvBridge()

        # Subscribers
        self.image_sub = self.create_subscription(
            Image, 'camera/image_raw', self.image_callback, 10
        )
        self.command_sub = self.create_subscription(
            String, 'vla/command', self.command_callback, 10
        )

        # Publishers
        self.action_pub = self.create_publisher(Float64MultiArray, 'vla/actions', 10)
        self.status_pub = self.create_publisher(String, 'vla/status', 10)

        # VLA state
        self.current_image = None
        self.current_command = None
        self.vla_model = self.initialize_vla_model()

        # Action space parameters
        self.action_space_dim = 7  # 7-DOF manipulator or similar
        self.max_action_value = 1.0

        # Processing queue
        self.process_queue = []

        self.get_logger().info('VLA Model initialized')

    def initialize_vla_model(self):
        """
        Initialize the VLA model (in practice, this would load a pre-trained model)
        For this example, we'll create a simple mock implementation
        """
        # In a real implementation, this would load a model like OpenVLA or RT-2
        # For simulation purposes, we'll create a mock model
        class MockVLA:
            def predict_action(self, image, command):
                # Mock implementation - in reality this would be a transformer-based model
                # that processes image + command and outputs actions

                # For demonstration, create actions based on simple heuristics
                # combined with learned patterns
                action = np.random.normal(0, 0.1, size=(7,))

                # Add some bias based on command keywords
                if 'lift' in command.lower() or 'raise' in command.lower():
                    action[2] += 0.3  # Move upward
                elif 'lower' in command.lower() or 'down' in command.lower():
                    action[2] -= 0.3  # Move downward

                if 'left' in command.lower():
                    action[0] -= 0.2  # Move left
                elif 'right' in command.lower():
                    action[0] += 0.2  # Move right

                if 'forward' in command.lower():
                    action[1] += 0.2  # Move forward
                elif 'backward' in command.lower() or 'back' in command.lower():
                    action[1] -= 0.2  # Move backward

                return action

        return MockVLA()

    def image_callback(self, msg):
        """Handle incoming camera images"""
        try:
            cv_image = self.bridge.imgmsg_to_cv2(msg, "bgr8")
            self.current_image = cv_image

            # Process if we have both image and command
            if self.current_command:
                self.process_vla_inference()

        except Exception as e:
            self.get_logger().error(f'Error processing image: {e}')

    def command_callback(self, msg):
        """Handle incoming language commands"""
        self.current_command = msg.data

        # Process if we have both image and command
        if self.current_image:
            self.process_vla_inference()

    def process_vla_inference(self):
        """Process VLA inference when both image and command are available"""
        if self.current_image is None or self.current_command is None:
            return

        try:
            # Get action prediction from VLA model
            action = self.vla_model.predict_action(self.current_image, self.current_command)

            # Clip actions to valid range
            action = np.clip(action, -self.max_action_value, self.max_action_value)

            # Publish action
            action_msg = Float64MultiArray()
            action_msg.data = action.tolist()
            self.action_pub.publish(action_msg)

            # Publish status
            status_msg = String()
            status_msg.data = f'VLA executed: {self.current_command}'
            self.status_pub.publish(status_msg)

            self.get_logger().info(f'VLA executed command: {self.current_command}, action: {action[:3]}...')

            # Clear processed command (in a real system, you might want to keep it for continuous control)
            self.current_command = None

        except Exception as e:
            self.get_logger().error(f'Error in VLA inference: {e}')
            status_msg = String()
            status_msg.data = f'VLA error: {str(e)}'
            self.status_pub.publish(status_msg)

    def get_current_vla_state(self):
        """Get current VLA state for other nodes"""
        return {
            'image_available': self.current_image is not None,
            'command_available': self.current_command is not None,
            'model_initialized': self.vla_model is not None
        }


def main(args=None):
    rclpy.init(args=args)

    vla_model = VLAModel()

    try:
        rclpy.spin(vla_model)
    except KeyboardInterrupt:
        vla_model.get_logger().info('Shutting down VLA model')
    finally:
        vla_model.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### VLA Integration with ROS 2

```python
#!/usr/bin/env python3

"""
VLA Integration Node
Integrates VLA model with ROS 2 control stack
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from std_msgs.msg import String
from geometry_msgs.msg import Twist
from control_msgs.msg import JointTrajectoryControllerState
from trajectory_msgs.msg import JointTrajectory, JointTrajectoryPoint
from builtin_interfaces.msg import Duration
import numpy as np
from typing import List, Optional


class VLAIntegration(Node):
    def __init__(self):
        super().__init__('vla_integration')

        # Subscribers
        self.vla_action_sub = self.create_subscription(
            String, 'vla/actions_processed', self.vla_action_callback, 10
        )
        self.joint_state_sub = self.create_subscription(
            JointTrajectoryControllerState, 'joint_states', self.joint_state_callback, 10
        )

        # Publishers
        self.joint_cmd_pub = self.create_publisher(JointTrajectory, 'joint_trajectory_controller/joint_trajectory', 10)
        self.velocity_cmd_pub = self.create_publisher(Twist, 'cmd_vel', 10)

        # VLA integration state
        self.current_joint_positions = []
        self.current_action = None
        self.robot_type = 'manipulator'  # or 'mobile_base'

        # Action scaling parameters
        self.action_scale = 0.1  # Scale factor for action magnitude
        self.dt = 0.1  # Time step for trajectory generation

        self.get_logger().info('VLA Integration initialized')

    def vla_action_callback(self, msg):
        """Handle VLA action predictions"""
        try:
            # Parse action from message (in practice, this would be Float64MultiArray)
            action_str = msg.data.strip('[]')
            action_values = [float(x.strip()) for x in action_str.split(',')]
            action = np.array(action_values)

            self.current_action = action
            self.execute_vla_action()

        except Exception as e:
            self.get_logger().error(f'Error parsing VLA action: {e}')

    def joint_state_callback(self, msg):
        """Handle joint state updates"""
        self.current_joint_positions = list(msg.actual.positions)

    def execute_vla_action(self):
        """Execute VLA action based on robot type"""
        if self.current_action is None:
            return

        if self.robot_type == 'manipulator':
            self.execute_manipulator_action()
        elif self.robot_type == 'mobile_base':
            self.execute_mobile_base_action()
        else:
            self.get_logger().warn(f'Unknown robot type: {self.robot_type}')

    def execute_manipulator_action(self):
        """Execute action for manipulator robot"""
        if len(self.current_action) < 7:
            self.get_logger().warn('Insufficient action dimensions for manipulator')
            return

        # Create joint trajectory command
        trajectory = JointTrajectory()
        trajectory.joint_names = ['joint1', 'joint2', 'joint3', 'joint4', 'joint5', 'joint6', 'joint7']

        # Calculate target positions based on current positions + scaled action
        if len(self.current_joint_positions) >= 7:
            target_positions = []
            for i in range(7):
                current_pos = self.current_joint_positions[i] if i < len(self.current_joint_positions) else 0.0
                target_pos = current_pos + self.current_action[i] * self.action_scale
                target_positions.append(target_pos)
        else:
            # Default starting positions if joint states not available
            target_positions = self.current_action[:7] * self.action_scale

        # Create trajectory point
        point = JointTrajectoryPoint()
        point.positions = target_positions
        point.velocities = [0.0] * 7  # Zero velocity at target
        point.accelerations = [0.0] * 7  # Zero acceleration at target
        point.time_from_start = Duration(sec=int(self.dt), nanosec=0)

        trajectory.points = [point]

        # Publish trajectory
        self.joint_cmd_pub.publish(trajectory)
        self.get_logger().info(f'Published manipulator trajectory: {target_positions[:3]}...')

    def execute_mobile_base_action(self):
        """Execute action for mobile base robot"""
        if len(self.current_action) < 2:
            self.get_logger().warn('Insufficient action dimensions for mobile base')
            return

        # Interpret first two dimensions as linear and angular velocities
        linear_vel = self.current_action[0] * self.action_scale
        angular_vel = self.current_action[1] * self.action_scale

        # Create twist command
        twist = Twist()
        twist.linear.x = float(linear_vel)
        twist.angular.z = float(angular_vel)

        # Publish velocity command
        self.velocity_cmd_pub.publish(twist)
        self.get_logger().info(f'Published mobile base command: linear={linear_vel:.3f}, angular={angular_vel:.3f}')

    def set_robot_type(self, robot_type: str):
        """Set the robot type for action interpretation"""
        self.robot_type = robot_type
        self.get_logger().info(f'VLA robot type set to: {robot_type}')


def main(args=None):
    rclpy.init(args=args)

    vla_integration = VLAIntegration()

    try:
        rclpy.spin(vla_integration)
    except KeyboardInterrupt:
        vla_integration.get_logger().info('Shutting down VLA integration')
    finally:
        vla_integration.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

```python
#!/usr/bin/env python3

"""
VLA Data Collection Node
Collects demonstration data for VLA model training
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, JointState
from geometry_msgs.msg import Twist
from std_msgs.msg import String
from cv_bridge import CvBridge
import numpy as np
import json
import os
from datetime import datetime
from typing import List, Dict, Optional


class VLADataCollector(Node):
    def __init__(self):
        super().__init__('vla_data_collector')

        # CV Bridge for image processing
        self.bridge = CvBridge()

        # Subscribers
        self.image_sub = self.create_subscription(
            Image, 'camera/image_raw', self.image_callback, 10
        )
        self.joint_state_sub = self.create_subscription(
            JointState, 'joint_states', self.joint_state_callback, 10
        )
        self.cmd_vel_sub = self.create_subscription(
            Twist, 'cmd_vel', self.cmd_vel_callback, 10
        )
        self.command_sub = self.create_subscription(
            String, 'vla/command', self.command_callback, 10
        )

        # Data collection state
        self.current_image = None
        self.current_joints = None
        self.current_command = None
        self.current_action = None
        self.data_buffer = []
        self.collection_active = False

        # Data storage parameters
        self.data_dir = '/tmp/vla_demonstrations'
        self.max_buffer_size = 100  # Maximum demonstrations to keep in memory
        self.save_interval = 10  # Save every N demonstrations

        # Create data directory
        os.makedirs(self.data_dir, exist_ok=True)

        # Timer for periodic saving
        self.save_timer = self.create_timer(5.0, self.periodic_save)

        self.get_logger().info('VLA Data Collector initialized')

    def image_callback(self, msg):
        """Handle incoming camera images"""
        try:
            cv_image = self.bridge.imgmsg_to_cv2(msg, "bgr8")
            self.current_image = cv_image
        except Exception as e:
            self.get_logger().error(f'Error processing image: {e}')

    def joint_state_callback(self, msg):
        """Handle joint state updates"""
        self.current_joints = list(msg.position)

    def cmd_vel_callback(self, msg):
        """Handle velocity commands (as proxy for actions)"""
        action = [msg.linear.x, msg.angular.z]  # For mobile base
        self.current_action = action

    def command_callback(self, msg):
        """Handle language commands"""
        self.current_command = msg.data

    def start_collection(self):
        """Start data collection"""
        self.collection_active = True
        self.get_logger().info('VLA data collection started')

    def stop_collection(self):
        """Stop data collection"""
        self.collection_active = False
        self.get_logger().info('VLA data collection stopped')

    def record_demonstration(self):
        """Record a single demonstration step"""
        if not self.collection_active:
            return False

        if (self.current_image is None or
            self.current_command is None or
            self.current_action is None):
            return False

        # Create demonstration record
        demo_record = {
            'timestamp': datetime.now().isoformat(),
            'image_shape': self.current_image.shape if self.current_image is not None else None,
            'command': self.current_command,
            'action': self.current_action.copy() if self.current_action is not None else [],
            'joints': self.current_joints.copy() if self.current_joints is not None else [],
            # In a real system, we'd encode the image or save separately
            # For this example, we'll just note that image exists
            'has_image': self.current_image is not None
        }

        # Add to buffer
        self.data_buffer.append(demo_record)

        # Limit buffer size
        if len(self.data_buffer) > self.max_buffer_size:
            self.data_buffer.pop(0)  # Remove oldest record

        self.get_logger().info(f'Recorded demonstration: {self.current_command}')
        return True

    def periodic_save(self):
        """Periodically save collected data"""
        if len(self.data_buffer) >= self.save_interval:
            self.save_demonstrations()

    def save_demonstrations(self):
        """Save collected demonstrations to file"""
        if not self.data_buffer:
            return

        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"vla_demonstrations_{timestamp}.json"
        filepath = os.path.join(self.data_dir, filename)

        # Prepare data for saving (in a real system, images would be saved separately)
        save_data = {
            'metadata': {
                'collection_date': datetime.now().isoformat(),
                'num_demonstrations': len(self.data_buffer),
                'robot_type': 'simulated',
                'environment': 'gazebo_simulation'
            },
            'demonstrations': self.data_buffer.copy()
        }

        try:
            with open(filepath, 'w') as f:
                json.dump(save_data, f, indent=2)

            self.get_logger().info(f'Saved {len(self.data_buffer)} demonstrations to {filepath}')

            # Clear buffer after saving
            self.data_buffer.clear()

        except Exception as e:
            self.get_logger().error(f'Error saving demonstrations: {e}')

    def get_collection_stats(self):
        """Get statistics about collected data"""
        return {
            'buffer_size': len(self.data_buffer),
            'collection_active': self.collection_active,
            'data_directory': self.data_dir
        }


def main(args=None):
    rclpy.init(args=args)

    collector = VLADataCollector()

    # Example: Start collection after a delay
    def start_collecting():
        collector.start_collection()

    # Start collecting after 2 seconds
    timer = collector.create_timer(2.0, start_collecting)

    try:
        rclpy.spin(collector)
    except KeyboardInterrupt:
        collector.get_logger().info('Shutting down VLA data collector')
        collector.save_demonstrations()  # Save remaining data
    finally:
        collector.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Safety and Deployment Considerations

### VLA Safety Monitor

```python
#!/usr/bin/env python3

"""
VLA Safety Monitor
Monitors VLA actions for safety violations
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool, Float64MultiArray
from geometry_msgs.msg import Twist, Pose
from sensor_msgs.msg import JointState, LaserScan
import numpy as np
from typing import List, Dict, Optional


class VLASafetyMonitor(Node):
    def __init__(self):
        super().__init__('vla_safety_monitor')

        # Subscribers
        self.vla_action_sub = self.create_subscription(
            Float64MultiArray, 'vla/actions_unsafe', self.unsafe_action_callback, 10
        )
        self.safe_action_pub = self.create_publisher(Float64MultiArray, 'vla/actions_safe', 10)
        self.emergency_stop_pub = self.create_publisher(Bool, 'emergency_stop', 10)
        self.safety_status_pub = self.create_publisher(String, 'vla/safety_status', 10)

        # Sensor subscribers for safety checks
        self.laser_sub = self.create_subscription(
            LaserScan, 'scan', self.laser_callback, 10
        )
        self.joint_state_sub = self.create_subscription(
            JointState, 'joint_states', self.joint_state_callback, 10
        )

        # Safety parameters
        self.min_distance_threshold = 0.3  # meters
        self.max_joint_velocity = 0.5  # rad/s
        self.max_linear_velocity = 0.2  # m/s
        self.max_angular_velocity = 0.5  # rad/s
        self.dead_man_timeout = 1.0  # seconds

        # Safety state
        self.laser_ranges = []
        self.joint_positions = []
        self.joint_velocities = []
        self.last_vla_action_time = None
        self.emergency_stop_active = False

        # Safety check timer
        self.safety_check_timer = self.create_timer(0.1, self.safety_check)

        self.get_logger().info('VLA Safety Monitor initialized')

    def unsafe_action_callback(self, msg):
        """Handle potentially unsafe VLA actions"""
        if self.emergency_stop_active:
            return

        action = np.array(msg.data)

        # Apply safety checks
        safe_action = self.apply_safety_filters(action)

        # Publish safe action
        safe_msg = Float64MultiArray()
        safe_msg.data = safe_action.tolist()
        self.safe_action_pub.publish(safe_msg)

        # Update action time
        self.last_vla_action_time = self.get_clock().now()

        # Publish status
        status_msg = String()
        if not np.array_equal(action, safe_action):
            status_msg.data = 'Action modified for safety'
        else:
            status_msg.data = 'Action passed safety checks'
        self.safety_status_pub.publish(status_msg)

    def laser_callback(self, msg):
        """Handle laser scan data for obstacle detection"""
        self.laser_ranges = list(msg.ranges)

    def joint_state_callback(self, msg):
        """Handle joint state updates"""
        self.joint_positions = list(msg.position)
        self.joint_velocities = list(msg.velocity)

    def apply_safety_filters(self, action):
        """Apply safety filters to VLA action"""
        # Check if action is for mobile base (2D: linear, angular)
        if len(action) == 2:
            return self.filter_mobile_base_action(action)
        # Check if action is for manipulator (7D+ joint positions/velocities)
        elif len(action) >= 6:
            return self.filter_manipulator_action(action)
        else:
            # Unknown action type, return zeros
            return np.zeros_like(action)

    def filter_mobile_base_action(self, action):
        """Apply safety filters to mobile base actions"""
        linear_vel, angular_vel = action[0], action[1]

        # Check for obstacles in front
        if self.laser_ranges:
            # Check front 90-degree sector (45 degrees left/right of center)
            front_sector = self.laser_ranges[len(self.laser_ranges)//2 - len(self.laser_ranges)//8 :
                                           len(self.laser_ranges)//2 + len(self.laser_ranges)//8]
            min_front_distance = min(front_sector) if front_sector else float('inf')

            # Reduce speed if obstacle is close
            if min_front_distance < self.min_distance_threshold:
                # Emergency stop if very close
                if min_front_distance < self.min_distance_threshold * 0.5:
                    self.trigger_emergency_stop()
                    return np.array([0.0, 0.0])  # Stop completely
                else:
                    # Scale down velocities proportionally
                    scale = min_front_distance / (self.min_distance_threshold * 0.5)
                    linear_vel *= scale
                    angular_vel *= scale

        # Limit velocities
        linear_vel = max(min(linear_vel, self.max_linear_velocity), -self.max_linear_velocity)
        angular_vel = max(min(angular_vel, self.max_angular_velocity), -self.max_angular_velocity)

        return np.array([linear_vel, angular_vel])

    def filter_manipulator_action(self, action):
        """Apply safety filters to manipulator actions"""
        filtered_action = action.copy()

        # Check joint limits if current positions are available
        if len(self.joint_positions) >= len(action):
            for i in range(len(action)):
                # Calculate target position
                target_pos = self.joint_positions[i] + action[i] * 0.01  # Small step for safety

                # Check for extreme positions (simplified - in practice, use URDF joint limits)
                if abs(target_pos) > 3.0:  # radians
                    filtered_action[i] = 0.0  # Don't move this joint

        # Limit velocities if joint velocities are available
        if len(self.joint_velocities) >= len(action):
            for i in range(len(action)):
                if abs(self.joint_velocities[i]) > self.max_joint_velocity:
                    # Reduce action to slow down
                    filtered_action[i] *= 0.5

        return filtered_action

    def safety_check(self):
        """Periodic safety checks"""
        # Check for dead man switch timeout
        if (self.last_vla_action_time is not None and
            (self.get_clock().now() - self.last_vla_action_time).nanoseconds * 1e-9 > self.dead_man_timeout):
            self.trigger_emergency_stop()

        # Check for emergency stop condition
        if self.emergency_stop_active:
            # Send zero velocity to stop robot
            zero_action = Float64MultiArray()
            zero_action.data = [0.0] * 7  # Assuming 7-DOF for safety
            self.safe_action_pub.publish(zero_action)

    def trigger_emergency_stop(self):
        """Trigger emergency stop"""
        if not self.emergency_stop_active:
            self.emergency_stop_active = True
            self.get_logger().error('VLA Safety Monitor: EMERGENCY STOP ACTIVATED')

            # Publish emergency stop signal
            emg_msg = Bool()
            emg_msg.data = True
            self.emergency_stop_pub.publish(emg_msg)

            # Send zero action to stop robot
            zero_action = Float64MultiArray()
            zero_action.data = [0.0] * 7
            self.safe_action_pub.publish(zero_action)

    def reset_safety_monitor(self):
        """Reset safety monitor after emergency stop"""
        self.emergency_stop_active = False
        self.get_logger().info('VLA Safety Monitor: Reset after emergency stop')

        # Publish reset signal
        emg_msg = Bool()
        emg_msg.data = False
        self.emergency_stop_pub.publish(emg_msg)


def main(args=None):
    rclpy.init(args=args)

    safety_monitor = VLASafetyMonitor()

    try:
        rclpy.spin(safety_monitor)
    except KeyboardInterrupt:
        safety_monitor.get_logger().info('Shutting down VLA safety monitor')
    finally:
        safety_monitor.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## VLA Evaluation and Metrics

### VLA Performance Evaluation Node

```python
#!/usr/bin/env python3

"""
VLA Performance Evaluation Node
Evaluates VLA system performance and safety metrics
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Float64
from geometry_msgs.msg import PoseStamped
import numpy as np
import time
from typing import List, Dict, Optional


class VLAEvaluator(Node):
    def __init__(self):
        super().__init__('vla_evaluator')

        # Publishers for metrics
        self.success_rate_pub = self.create_publisher(Float64, 'vla/success_rate', 10)
        self.safety_violations_pub = self.create_publisher(Float64, 'vla/safety_violations', 10)
        self.response_time_pub = self.create_publisher(Float64, 'vla/response_time', 10)
        self.task_completion_pub = self.create_publisher(Float64, 'vla/task_completion', 10)

        # Evaluation state
        self.eval_trials = 0
        self.eval_successes = 0
        self.eval_safety_violations = 0
        self.eval_response_times = []
        self.eval_task_completions = []

        # Evaluation timer
        self.eval_timer = self.create_timer(10.0, self.publish_evaluation_metrics)

        self.get_logger().info('VLA Evaluator initialized')

    def record_trial_result(self, success: bool, safety_violation: bool = False,
                           response_time: float = 0.0, task_completed: bool = False):
        """Record results of a single evaluation trial"""
        self.eval_trials += 1
        if success:
            self.eval_successes += 1
        if safety_violation:
            self.eval_safety_violations += 1
        if response_time > 0:
            self.eval_response_times.append(response_time)
        if task_completed:
            self.eval_task_completions.append(task_completed)

    def publish_evaluation_metrics(self):
        """Publish current evaluation metrics"""
        if self.eval_trials > 0:
            # Success rate
            success_rate = self.eval_successes / self.eval_trials
            rate_msg = Float64()
            rate_msg.data = float(success_rate)
            self.success_rate_pub.publish(rate_msg)

            # Safety violations rate
            safety_rate = self.eval_safety_violations / self.eval_trials
            safety_msg = Float64()
            safety_msg.data = float(safety_rate)
            self.safety_violations_pub.publish(safety_msg)

            # Average response time
            if self.eval_response_times:
                avg_response_time = np.mean(self.eval_response_times)
                time_msg = Float64()
                time_msg.data = float(avg_response_time)
                self.response_time_pub.publish(time_msg)

            # Task completion rate
            if self.eval_task_completions:
                task_completion_rate = sum(self.eval_task_completions) / len(self.eval_task_completions)
                completion_msg = Float64()
                completion_msg.data = float(task_completion_rate)
                self.task_completion_pub.publish(completion_msg)

            self.get_logger().info(
                f'VLA Metrics - Trials: {self.eval_trials}, '
                f'Success Rate: {success_rate:.2f}, '
                f'Safety Violations: {safety_rate:.2f}, '
                f'Avg Response Time: {np.mean(self.eval_response_times) if self.eval_response_times else 0:.3f}s'
            )

    def get_current_metrics(self) -> Dict:
        """Get current evaluation metrics"""
        return {
            'trials': self.eval_trials,
            'successes': self.eval_successes,
            'success_rate': self.eval_successes / self.eval_trials if self.eval_trials > 0 else 0,
            'safety_violations': self.eval_safety_violations,
            'avg_response_time': np.mean(self.eval_response_times) if self.eval_response_times else 0,
            'task_completion_rate': (
                sum(self.eval_task_completions) / len(self.eval_task_completions)
                if self.eval_task_completions else 0
            )
        }

    def reset_evaluation(self):
        """Reset evaluation counters"""
        self.eval_trials = 0
        self.eval_successes = 0
        self.eval_safety_violations = 0
        self.eval_response_times.clear()
        self.eval_task_completions.clear()
        self.get_logger().info('VLA Evaluator: Counters reset')


def main(args=None):
    rclpy.init(args=args)

    evaluator = VLAEvaluator()

    # Example: Record some mock evaluation results
    def record_mock_results():
        # Simulate evaluation results
        for _ in range(5):

            response_time = np.random.uniform(0.1, 0.5)  # 0.1-0.5s response time
            task_completed = success  # Task completion tied to success

            evaluator.record_trial_result(success, safety_violation, response_time, task_completed)

    # Record mock results periodically
    mock_timer = evaluator.create_timer(3.0, record_mock_results)

    try:
        rclpy.spin(evaluator)
    except KeyboardInterrupt:
        evaluator.get_logger().info('Shutting down VLA evaluator')
    finally:
        evaluator.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Key Considerations for VLA Systems

### 1. Training Data Requirements

- **Large-scale demonstrations**: VLA models require extensive datasets of human demonstrations
- **Diverse scenarios**: Training data must cover various objects, environments, and tasks
- **Multi-embodiment data**: Data from multiple robot platforms improves generalization

### 2. Computational Requirements

- **High-performance GPUs**: Training requires significant computational resources
- **Real-time inference**: Deployment requires efficient models for real-time control
- **Edge optimization**: Quantization and pruning for deployment on robot hardware

### 3. Safety and Reliability

- **Action space constraints**: Ensuring VLA outputs remain within safe operational bounds
- **Fail-safe mechanisms**: Emergency stop and fallback behaviors
- **Uncertainty quantification**: Identifying when VLA is uncertain and should defer to human operator
