# ماڈیول 3: نیویگیشن اور جسمانی اے آئی

**دورانیہ**: ہفتے 8-10 | **ٹیئر سپورٹ**: 🟢 A • 🔵 B • 🟣 C

## سیکھنے کا نتیجہ

ماڈیول 3 کے اختتام تک، آپ **Nav2 اور VSLAM کا استعمال کرتے ہوئے وائس-ٹو-نیویگیشن پائپ لائنز کو ڈیپلائی کریں گے**، جس سے روبوٹس خودکار طور پر ماحول کو میپ کر سکیں، خود کو مقام دے سکیں، رکاوٹ سے پاک راستے کی منصوبہ بندی کر سکیں، اور "کچن میں جاؤ" جیسے قدرتی زبان کے حکم کا جواب دے سکیں۔

---

## جائزہ

ماڈیول 3 **ادراک** اور **عمل** کے درمیان پُل ڈالتا ہے کیونکہ یہ آپ کو سکھاتا ہے کہ روبوٹس نامعلوم ماحول میں خودکار طور پر کیسے نیویگیٹ کریں۔ آپ ماسٹر کریں گے:

- **SLAM (ہم آہنگ مقام کاری اور میپنگ)**: روبوٹ کی پوزیشن ٹریک کرتے ہوئے میپس تیار کرنا
- **Nav2 اسٹیک**: ROS 2 کا پروڈکشن گریڈ نیویگیشن فریم ورک جو گوداموں، ہسپتالوں، اور گھروں میں استعمال ہوتا ہے
- **سینسر فیوژن**: مضبوط مقام کاری کے لیے LiDAR، کیمرے، IMU، اور ویل اودومیٹر کو ملانا
- **VSLAM (بصری SLAM)**: GPS-سے-مکمل طور پر محروم ماحول کے لیے صرف کیمرہ نیویگیشن
- **وائس-کنٹرولڈ نیویگیشن**: Nav2 ویپوائنٹ فالوونگ کے ساتھ اسپیچ ریکگنیشن کا انضمام

یہیں آپ کا ROS 2 علم (ماڈیول 1) اور سیمولیشن کے مہارتوں (ماڈیول 2) **حقیقی خودکار سسٹمز** میں مل جاتا ہے۔

---

## یہ ماڈیول کیوں اہم ہے

**خودکار نیویگیشن موبائل روبوٹکس کی بنیاد ہے**:

- **گودام کے روبوٹس** (Amazon، Fetch Robotics) سامان کی ترسیل کے لیے Nav2 استعمال کرتے ہیں
- **گھریلو روبوٹس** (iRobot، Boston Dynamics Spot) گھروں کو میپ کرتے ہیں اور کمرے میں نیویگیٹ کرتے ہیں
- **ہیومنوائڈ روبوٹس** (Tesla Optimus، Unitree G1) متحرک ماحول کے لیے VSLAM کی ضرورت رکھتے ہیں

**ریل ورلڈ ایپلی کیشنز**:

- **گھریلو روبوٹس**: کلیننگ، سیکورٹی، کمپنی فراہم کرنا
- **انڈسٹریل ایپلی کیشنز**: مواد کی منتقلی، اسٹاک ٹریکنگ، معائنہ
- **ہیلتھ کیئر**: مریض کی دیکھ بھال، ادویات کی ترسیل، ہسپتال کی سروسز
- **ریسٹورنٹس**: فوڈ سروس، آرڈر ڈیلیوری، صفائی

**چیلنجز**:

- **متحرک ماحول**: چلتے ہوئے لوگ، کھڑے ہوئے اشیاء، تبدیل ہوتے ہوئے مناظر
- **سیکیورٹی**: نیویگیشن کے دوران روبوٹ اور انسان کی حفاظت
- **کارکردگی**: حقیقی وقت میں راستہ تلاش کرنا اور رکاوٹ سے بچنا
- **کارکردگی**: محدود وسائل کے ساتھ کام کرنا (CPU، بجلی، میموری)
