# ماڈیول 2: سیمولیشن اور ڈیجیٹل ٹوئنز

**دورانیہ**: ہفتے 6-7 | **ٹیئر سپورٹ**: 🟢 A • 🔵 B • 🟣 C

## سیکھنے کا نتیجہ

ماڈیول 2 کے اختتام تک، آپ **تیز ترقی کے لیے حقیقی روبوٹ سیمولیشن تیار کریں گے**، جس میں ڈیجیٹل ٹوئنز تیار کرنے کے لیے گیزبو اور اسیک سیم کو ماسٹر کریں گے— جسمانی روبوٹس کی ورچوئل نقل جو خطرہ سے پاک تجربہ کاری اور متوازی ترقی کو فعال کرتی ہے۔

---

## جائزہ

ماڈیول 2 **سیمولیشن-فرسٹ ڈویلپمنٹ پیراڈائم** سکھاتا ہے جو جدید روبوٹکس انجینئرنگ کو طاقت دیتا ہے۔ مہنگے ہارڈ ویئر پر براہ راست ڈیبگنگ کے بجائے، آپ سیکھیں گے:

- **ڈیجیٹل ٹوئنز تیار کرنا** جو جسمانی روبوٹ کے رویے کو زیادہ وفاداری کے ساتھ نقل کرتے ہیں
- **ترقی کو تیز کرنا** سیمولیشن میں 100+ منظرنامے ٹیسٹ کرکے اس سے پہلے کہ ہارڈ ویئر پر عمل کیا جائے
- **گیزبو ماسٹر کرنا** CPU دوست، اوپن سورس روبوٹکس سیمولیشن کے لیے
- **اسیک سیم کو استعمال کرنا** GPU-ایکسلریٹڈ، فوٹو ریلائزٹک ماحول کے لیے
- **سیم2ریئل کو پُل دینا** ڈومین رینڈمائزیشن اور ٹرانسفر لرننگ کو سمجھ کر

چاہے آپ نیا روبوٹ ڈیزائن کر رہے ہوں، نیویگیشن الگورتھم ٹیسٹ کر رہے ہوں، یا اے آئی ماڈلز تربیت دے رہے ہوں، سیمولیشن آپ کی طاقت کو بڑھانے والا ہے۔

---

## یہ ماڈیول کیوں اہم ہے

**ریل ورلڈ روبوٹکس ڈویلپمنٹ مہنگا اور سست ہے**:

- جسمانی روبوٹس کی قیمت $1,000–$100,000+ ہوتی ہے
- ہارڈ ویئر کی ناکامیوں کی مرمت اور بندش کی ضرورت ہوتی ہے
- خطرناک منظرناموں کی جانچ (رکاوٹ کے تصادم، کونے کے کیسز) سامان کو نقصان پہنچانے کا خطرہ رکھتی ہے
