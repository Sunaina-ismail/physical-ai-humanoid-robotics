# ماڈیول 4: وژن-زبان-عمل سسٹم

**دورانیہ**: ہفتے 11-13 | **ٹیئر سپورٹ**: 🟢 A • 🔵 B • 🟣 C

## سیکھنے کا نتیجہ

ماڈیول 4 کے اختتام تک، آپ **ایک VLA (وژن-زبان-عمل) ماڈل ڈیپلائی کریں گے جو قدرتی زبان کی تشریح کرتا ہے اور روبوٹ ایکشنز کو کنٹرول کرتا ہے**، جس سے روبوٹس "لال مگ کو اٹھائیں اور اسے الماری پر رکھیں" جیسے حکم کو سمجھ سکیں اور خودکار طور پر متعدد اقدامات والے مینیپولیشن اور نیویگیشن کام انجام دے سکیں۔

---

## جائزہ

ماڈیول 4 **کٹنگ ایج ملٹی ماڈل اے آئی** کو آپ کے روبوٹکس اسٹیک میں انضمام کرتا ہے، آپ کو یہ سکھاتا ہے کہ:

- **VLA آرکیٹیکچر کو سمجھیں**: کیسے ماڈلز جیسے OpenVLA اور RT-2 وژن انکوڈرز، زبانی ماڈلز، اور ایکشن ڈیکوڈرز کو جوڑتے ہیں
- **پری ٹرینڈ ماڈلز ڈیپلائی کریں**: روبوٹک مینیپولیشن کاموں کے لیے OpenVLA پر انفرینس چلائیں
- **VLA ماڈلز کو فائن ٹیون کریں**: اپنے ڈیٹا سیٹس کا استعمال کرتے ہوئے حسب ضرورت روبوٹس اور کاموں کے لیے ماڈلز کو ایڈجسٹ کریں
- **ایکشن اسپیسز ڈیزائن کریں**: ماڈل آؤٹ پٹس (ٹوکنائزڈ ایکشنز) کو ROS 2 ویلوسٹی کمانڈز یا جوائنٹ پوزیشنز میں میپ کریں
- **اینڈ ٹو اینڈ پائپ لائنز تیار کریں**: وائس → VLA → Nav2 → مینیپولیشن

یہ **روبوٹکس اے آئی کی سرحد** ہے— جہاں قدرتی زبان جسمانی سسٹم کو کنٹرول کرنے کا جامع انٹرفیس بن جاتی ہے۔

---

## یہ ماڈیول کیوں اہم ہے

**روایتی روبوٹکس پروگرامنگ ناکارہ ہے**:

- ہر کام کے لیے ہارڈ کوڈڈ "اگر-پھر" قواعد
- ادراک، منصوبہ بندی، اور کنٹرول کے لیے الگ سسٹم
- نئی اشیاء یا ماحول کے لیے جنرلائزیشن نہیں

**VLA سسٹم ان مسائل کو حل کرتے ہیں**:

- **اشاروں کی تشریح**: "وہ چیز" جیسے اشاروں کو سمجھنا
- **نئے کاموں کے لیے جنرلائزیشن**: نئی اشیاء اور ماحول کے لیے
- **قدرتی زبان کا انٹرفیس**: پروگرامنگ کے بغیر کنٹرول

**ریل ورلڈ ایپلی کیشنز**:

- **گھریلو روبوٹس**: کھانا لانا، صفائی کرنا، چیزوں کو لانا
- **صنعتی روبوٹس**: ایڈاپٹیو اسیمبلي، معائنہ
- **ہیلتھ کیئر**: مریض کی دیکھ بھال، ادویات کی ترسیل
- **سروس روبوٹس**: کسٹمر سروس، ڈیلیوری

**چیلنجز**:

- **ایکشن سپیس ڈیزائن**: ماڈل کے آؤٹ پٹس کو روبوٹ کنٹرول میں تبدیل کرنا
- **ڈیٹا کی ضرورت**: وسیع ڈیٹا سیٹس کی ضرورت
- **کارکردگی**: حقیقی وقت میں انفرینس
- **سیکیورٹی**: اے آئی ماڈل کی غلط استعمال سے حفاظت
